# 全局配置

## 快速开始

1. 编辑 `app/app_config.json` 修改配置
2. 运行 `dart run scripts/sync_config.dart` 同步配置

## 配置结构

所有配置统一在 `app/app_config.json` 管理：

```json
{
  "app": {
    "name": "fastapp",
    "version": "1.0.0",
    "buildNumber": 1,
    "description": "..."
  },
  "android": {
    "packageName": "...",
    "label": "fastapp"
  },
  "ios": {
    "bundleId": "...",
    "displayName": "fastapp",
    "bundleName": "fastapp"
  },
  "web": {
    "title": "fastapp",
    "shortName": "fastapp",
    "themeColor": "#0175C2",
    "backgroundColor": "#0175C2"
  },
  "network": {
    "apiBaseUrl": "...",
    "wsBaseUrl": "...",
    "connectionTimeout": 30000,
    "receiveTimeout": 15000,
    "endpoints": { ... }
  },
  "theme": {
    "seedColor": "#2196F3"
  },
  "resources": {
    "imageCdnBaseUrl": "..."
  },
  "assets": {
    "appLogo": "assets/icons/ic_appicon.png",

  "splash": {

  },

    "defaultHorizontalPadding": 12.0,
    "defaultVerticalPadding": 12.0,
    "defaultBorderRadius": 8.0
  }
}
```

## 配置分类

### 应用配置 (app)
- `name` - 应用名称
- `version` - 版本号
- `buildNumber` - 构建号
- `description` - 应用描述

### 平台配置
- **android** - 包名、应用标签
- **ios** - Bundle ID、显示名称
- **web** - 页面标题、主题色、图标路径

### 网络配置 (network)
- `apiBaseUrl` - API 基础 URL
- `wsBaseUrl` - WebSocket 基础 URL
- `connectionTimeout` - 连接超时（毫秒）
- `receiveTimeout` - 接收超时（毫秒）
- `endpoints` - API 端点路径

### 主题配置 (theme)
- `seedColor` - 主题种子颜色（用于生成 Material 3 颜色方案）

### 资源配置 (resources)
- `imageCdnBaseUrl` - 图片 CDN 基础 URL

### 资源路径 (assets)
- `appLogo` - 应用 Logo 路径
- `carBackground` - 登录页背景图片路径

### 启动图配置 (splash)
- `image` - 启动图图片路径（用于 Android、iOS、Web）
- `backgroundColor` - 启动图背景颜色
- `web.backgroundSize` - Web 端背景尺寸（cover/contain）
- `web.fadeOutTime` - Web 端淡出时间（毫秒）
- `web.hideDelay` - Web 端隐藏延迟（毫秒）

### 字体配置 (fonts)
- `productSans` - ProductSans 字体
- `roboto` - Roboto 字体

### UI 配置 (ui)
- `defaultHorizontalPadding` - 默认水平内边距
- `defaultVerticalPadding` - 默认垂直内边距
- `defaultBorderRadius` - 默认圆角半径

## 同步机制

配置会自动同步到以下文件：

- `lib/constants/app_config.dart` - Dart 代码常量
- `android/app/src/main/AndroidManifest.xml` - Android 清单（包括包名）
- `android/app/build.gradle` - Android 构建配置（包括包名）
- `ios/Runner/Info.plist` - iOS 配置
- `macos/Runner/Configs/AppInfo.xcconfig` - macOS 配置
- `web/index.html` - Web 页面
- `web/manifest.json` - Web 清单

> **注意**：
> - `project.pbxproj` 文件由 Xcode 自动管理，同步脚本已禁用对此文件的自动更新
> - 如需修改 iOS/macOS Bundle ID，请在 Xcode 中手动修改或使用 `xcodebuild` 命令
> - `app_config.json` 中的 `ios.bundleId` 仅用于记录，不会自动同步到项目文件

> **注意**：`Endpoints` 类直接使用 `AppConfig`，无需单独配置。

## 使用说明

### 在代码中使用配置

```dart
import 'package:boilerplate/constants/app_config.dart';

// 使用应用名称
Text(AppConfig.appName)

// 使用网络配置
final url = AppConfig.apiBaseUrl;

// 使用主题颜色
final color = Color(int.parse(AppConfig.seedColor.replaceFirst('#', '0xff')));

// 使用 UI 配置
BorderRadius.circular(AppConfig.defaultBorderRadius)
```

### 修改配置流程

1. 编辑 `app/app_config.json`
2. 运行同步脚本：`dart run scripts/sync_config.dart`
3. 重启应用使配置生效

## 注意事项

- ✅ 修改配置后必须运行同步脚本
- ✅ 不要直接修改 `app_config.dart`（自动生成）
- ✅ **Android 包名已支持配置化**：
  - 修改 `app_config.json` 中的 `android.packageName`
  - 运行同步脚本会自动更新 `build.gradle` 和 `AndroidManifest.xml`
- ⚠️ **iOS/macOS Bundle ID 需要手动管理**：
  - `project.pbxproj` 文件由 Xcode 自动管理，同步脚本已禁用自动更新
  - 如需修改 Bundle ID，请在 Xcode 中手动修改
  - `app_config.json` 中的 `ios.bundleId` 仅用于记录参考
