# 应用全局配置指南

## 概述

本项目使用 JSON 配置文件统一管理应用的所有配置，包括应用信息、平台配置、主题、网络、资源等。配置文件会自动同步到各个平台的配置文件和 Dart 代码中。

**核心理念：** 单一数据源 → 自动同步 → 全平台生效

## 快速开始

```bash
# 1. 编辑配置文件
vim app/app_config.json

# 2. 运行同步脚本
cd app
dart run scripts/sync_config.dart

# 3. 重启应用使配置生效
flutter run
```

### 2.1 应用配置 (app)

### 2.4 主题配置 (theme)

#### 配置项说明

主题分为 `light` 和 `dark` 两个模式，每个模式包含以下配置：

| 配置项 | 说明 | 格式 | 示例 |
|--------|------|------|------|
| `seedColor` | 主题种子颜色（生成 ColorScheme） | `#RRGGBB` | `#2196F3` |
| `scaffoldBackgroundColor` | Scaffold 背景色 | `#RRGGBB` 或 `null` | `#FFFFFF` |
| `buttonBackgroundColor` | 按钮背景色 | `#RRGGBB` | `#424242` |
| `buttonForegroundColor` | 按钮文字颜色 | `#RRGGBB` | `#FFFFFF` |
| `buttonDisabledBackgroundColor` | 禁用按钮背景色 | `#RRGGBB` | `#BDBDBD` |
| `buttonDisabledForegroundColor` | 禁用按钮文字颜色 | `#AARRGGBB` | `#B3FFFFFF` |

#### 颜色格式

- **十六进制**: `#RRGGBB` 或 `#AARRGGBB`
  - 例如: `#FFFFFF` (白色), `#424242` (深灰色)
  - 带透明度: `#B3FFFFFF` (70% 透明的白色)

- **null 值**: 使用系统默认颜色（推荐用于 `scaffoldBackgroundColor`）

#### 生成的 Dart 常量

同步后，`app_config.dart` 会包含以下常量：

```dart
class AppConfig {
  // Light 主题
  static const String seedColorLight = '#2196F3';
  static const String scaffoldBackgroundColorLight = '#FFFFFF';
  static const String buttonBackgroundColorLight = '#424242';
  static const String buttonForegroundColorLight = '#FFFFFF';
  static const String buttonDisabledBackgroundColorLight = '#BDBDBD';
  static const String buttonDisabledForegroundColorLight = '#B3FFFFFF';

  // Dark 主题
  static const String seedColorDark = '#2196F3';
  static const String scaffoldBackgroundColorDark = '';
  static const String buttonBackgroundColorDark = '#757575';
  static const String buttonForegroundColorDark = '#FFFFFF';
  static const String buttonDisabledBackgroundColorDark = '#616161';
  static const String buttonDisabledForegroundColorDark = '#B3FFFFFF';
}
```

#### 主题应用方式

`app_theme.dart` 会自动使用这些常量：

```dart
class AppTheme {
  static ThemeData _buildTheme(AppThemeType themeType) {
    final buttonBgColorString = themeType == AppThemeType.light
        ? AppConfig.buttonBackgroundColorLight
        : AppConfig.buttonBackgroundColorDark;
    final buttonBgColor = _hexToColor(buttonBgColorString);

    return ThemeData(
      colorScheme: ColorScheme.fromSeed(
        seedColor: _hexToColor(
          themeType == AppThemeType.light
            ? AppConfig.seedColorLight
            : AppConfig.seedColorDark
        ),
      ),
      elevatedButtonTheme: ElevatedButtonThemeData(
        style: ElevatedButton.styleFrom(
          backgroundColor: buttonBgColor,
          foregroundColor: _hexToColor(buttonFgColorString),
        ),
      ),
    );
  }
}
```

## 三、如何修改配置

### 3.1 基本流程

#### 步骤 1: 编辑 JSON 配置

编辑 `app/app_config.json`：

```json
{
  "theme": {
    "light": {
      "buttonBackgroundColor": "#1976D2"  // 改为蓝色
    }
  }
}
```

#### 步骤 2: 运行同步脚本

```bash
cd app
dart run scripts/sync_config.dart
```

#### 步骤 3: 重启应用

配置会自动应用到所有使用主题的地方。

### 3.2 配置同步目标

配置会自动同步到以下文件：

- ✅ `lib/constants/app_config.dart` - Dart 代码常量
- ✅ `android/app/src/main/AndroidManifest.xml` - Android 清单（包括包名）
- ✅ `android/app/build.gradle` - Android 构建配置（包括包名）
- ✅ `android/app/src/main/res/drawable/launch_background_image.png` - Android 启动图资源
- ✅ `ios/Runner/Info.plist` - iOS 配置
- ✅ `macos/Runner/Configs/AppInfo.xcconfig` - macOS 配置
- ✅ `web/index.html` - Web 页面
- ✅ `web/manifest.json` - Web 清单
- ⚠️ `ios/Runner.xcodeproj/project.pbxproj` - iOS 项目文件（需手动管理）

### 3.3 在代码中使用配置

```dart
import 'package:fastapp/constants/app_config.dart';

// 使用应用名称
Text(AppConfig.appName)

// 使用网络配置
final url = AppConfig.apiBaseUrl;

// 使用主题颜色
final color = Color(int.parse(AppConfig.seedColorLight.replaceFirst('#', '0xff')));

// 使用 UI 配置
BorderRadius.circular(AppConfig.defaultBorderRadius)
```

## 四、主题颜色管理

### 4.1 使用主题默认颜色（推荐）

对于 `ElevatedButton`，移除明确的颜色设置，使用主题默认：

```dart
// ❌ 旧代码
ElevatedButton(
  style: ElevatedButton.styleFrom(
    backgroundColor: Colors.amber,
    foregroundColor: Colors.black87,
  ),
  child: Text('按钮'),
)

// ✅ 新代码
ElevatedButton(
  // 不设置 backgroundColor，自动使用主题定义的深灰色
  child: Text('按钮'),
)
```

### 4.2 使用颜色常量（灵活）

使用新建的 `AppColors` 常量：

```dart
import 'package:fastapp/constants/app_colors.dart';

ElevatedButton(
  style: ElevatedButton.styleFrom(
    backgroundColor: AppColors.primaryButtonColor,
    foregroundColor: AppColors.primaryButtonTextColor,
  ),
  child: Text('按钮'),
)
```

### 4.3 特殊情况处理

#### 状态指示器（警告、待审核等）

对于表示"警告"或"待处理"状态的黄色UI，建议：

- **警告**: 改用橙色 `AppColors.warningColor` 或 `Colors.orange`
- **待审核**: 改用蓝色 `AppColors.infoColor` 或保持浅黄色作为背景色

示例：
```dart
// 警告框 - 可保留黄色背景但调整浓度
Container(
  color: Colors.amber[50],  // 非常浅的黄色背景
  decoration: BoxDecoration(
    border: Border.all(color: Colors.orange[300]!),  // 橙色边框
  ),
)
```

#### 图标和徽章颜色

对于非主要操作按钮的黄色图标或徽章：
- 考虑保留或改为主题色
- 根据语义选择颜色（如：VIP 徽章可使用金色）

## 五、资源生成

### 5.1 生成应用图标和启动图

使用资源管理脚本从 `app_config.json` 中的配置生成 Android 和 iOS 所需的各种尺寸图标和启动图：

```bash
# 在 app/ 目录下运行
cd app

# 生成图标并同步启动图
dart run scripts/launch_screen.dart all

# 仅生成图标
dart run scripts/launch_screen.dart icons

# 仅同步启动图
dart run scripts/launch_screen.dart launch
```

### 5.2 脚本功能

脚本会：
- 从 `app_config.json` 读取 `assets.appLogo` 路径（默认：`assets/images/launch/logo.png`）
- 自动生成 Android 所有密度图标（mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi）
- 自动生成 iOS 所有尺寸图标（根据 `Contents.json` 配置）
- 同步各平台的启动图配置

### 5.3 注意事项

- ✅ 源图片建议使用 1024x1024 或更大的正方形 PNG 图片
- ✅ 确保已安装 `image` 包依赖（运行 `flutter pub get`）
- ✅ 详细说明请查看 [脚本使用指南.md](scripts.md)

## 六、最佳实践

### ✅ 推荐做法

1. **统一在 JSON 中配置**: 所有可配置项都放在 `app_config.json`
2. **使用有意义的颜色值**: 不要用 `#000000` 这种极端值，除非确实需要
3. **保持 Light 和 Dark 主题的一致性**: 两者应该有相似的设计语言
4. **运行同步后提交**: 同步脚本的输出文件也需要 commit
5. **使用主题默认颜色**: 尽量让组件使用主题定义的默认颜色
6. **渐进式迁移**: 优先修改用户最常用的页面

### ❌ 避免

1. **不要绕过同步脚本**: 不要手动修改生成的文件（`app_config.dart`）
2. **不要在 app_theme.dart 中硬编码颜色**: 应该从 `AppConfig` 读取
3. **不要忘记运行同步脚本**: 修改 JSON 后必须同步
4. **不要一次性批量替换**: 每个页面的颜色可能有不同的语义，需要逐个判断
5. **不要直接修改生成的配置文件**: `app_config.dart` 由脚本自动生成，手动修改会被覆盖

## 七、常见问题

### Q1: 修改 JSON 后，Dart 代码没有变化？

**A**: 确保运行了同步脚本：
```bash
cd app
dart run scripts/sync_config.dart
```

### Q2: 可以直接修改 app_config.dart 吗？

**A**: **不可以！** `app_config.dart` 由脚本自动生成，手动修改会被覆盖。始终编辑 `app_config.json`，然后运行同步脚本。

### Q3: 如何添加新的配置项？

1. 在 `app_config.json` 中添加新字段
2. 在 `scripts/sync_config.dart` 中添加对应的正则替换规则
3. 在 `app_config.dart` 中手动添加新的常量声明（作为模板）
4. 运行同步脚本

### Q4: 颜色不生效？

检查：
1. JSON 中的颜色格式是否正确（`#RRGGBB`）
2. 是否运行了同步脚本
3. 是否重启了应用（热重载可能不够）

### Q5: null 值和空字符串的区别？

- `null` (JSON): 表示使用系统默认
- `""` (空字符串): 也表示使用系统默认
- `"#FFFFFF"`: 明确指定白色

在 Dart 代码中：
```dart
final color = colorString.isNotEmpty ? _hexToColor(colorString) : null;
```

### Q6: 如何修改 Android 包名？

1. 修改 `app_config.json` 中的 `android.packageName`
2. 运行 `dart run scripts/sync_config.dart`
3. 包名会自动同步到 `AndroidManifest.xml` 和 `build.gradle`

### Q7: 如何修改 iOS Bundle ID？

iOS/macOS 的 `project.pbxproj` 文件由 Xcode 自动管理，需要在 Xcode 中手动修改 Bundle ID。`app_config.json` 中的 `ios.bundleId` 仅用于记录。

### Q8: 主题修改后，部分页面颜色没变？

可能原因：
1. 页面硬编码了颜色值（如 `Colors.amber`）
2. 使用了旧的颜色常量
3. 页面没有重新加载（尝试热重启而非热重载）

解决方法：
1. 查找页面中的硬编码颜色并移除
2. 改用主题默认颜色或 `AppColors` 常量
3. 完全重启应用
