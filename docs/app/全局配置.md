# 应用全局配置指南

## 概述

本项目使用 JSON 配置文件统一管理应用配置，主题配置独立管理。配置会自动同步到各平台。

**核心理念：** 单一数据源 → 自动同步 → 全平台生效

## 快速开始

```bash
# 1. 编辑配置文件
vim app/app_config.json          # 应用配置
vim app/config/themes/light.json # 主题配置

# 2. 运行同步脚本
cd app
dart run scripts/sync_config.dart

# 3. 重启应用
flutter run
```

## 一、配置文件结构

### 核心文件

```
app/
├── app_config.json              # 应用配置（网络、版本等）
├── config/themes/               # 主题配置目录
│   ├── theme_config.json        # 主题元数据
│   ├── light.json               # 亮色主题
│   └── dark.json                # 暗色主题
├── lib/constants/
│   ├── app_config.dart          # 自动生成的应用配置
│   ├── theme_config.dart        # 主题配置加载类
│   └── app_theme.dart           # 主题构建器
└── scripts/
    ├── sync_config.dart         # 配置同步脚本
    └── launch_screen.dart       # 启动图生成脚本
```

### 同步流程

```
应用配置流程：
app_config.json → sync_config.dart → app_config.dart → 各平台配置文件

主题配置流程：
config/themes/*.json → theme_config.dart → app_theme.dart → 应用主题
```

## 二、应用配置 (app_config.json)

### 完整配置示例

```json
{
  "app": {
    "name": "fastapp",
    "version": "1.0.0",
    "buildNumber": 1,
    "description": "FastApp - 快速开发框架"
  },
  "android": {
    "packageName": "com.example.fastapp",
    "label": "fastapp"
  },
  "ios": {
    "bundleId": "com.example.fastapp",
    "displayName": "fastapp",
    "bundleName": "fastapp"
  },
  "web": {
    "title": "fastapp",
    "shortName": "fastapp",
    "themeColor": "#0175C2",
    "backgroundColor": "#0175C2"
  },
  "network": {
    "apiBaseUrl": "http://192.168.1.4:9501",
    "wsBaseUrl": "ws://192.168.1.4:9502/ws",
    "connectionTimeout": 30000,
    "receiveTimeout": 15000,
    "sendTimeout": 5000
  },
  "resources": {
    "imageCdnBaseUrl": "http://127.0.0.1:9501/api/file?path="
  },
  "ui": {
    "defaultHorizontalPadding": 12.0,
    "defaultVerticalPadding": 12.0,
    "defaultBorderRadius": 8.0
  }
}
```

### 配置项说明

#### 应用配置 (app)
- `name`: 应用名称
- `version`: 版本号
- `buildNumber`: 构建号
- `description`: 应用描述

#### 平台配置
- `android.packageName`: Android 包名（同步到 AndroidManifest.xml）
- `ios.bundleId`: iOS Bundle ID（仅记录，需在 Xcode 手动修改）
- `web.title`: Web 页面标题

#### 网络配置 (network)
- `apiBaseUrl`: API 基础 URL
- `wsBaseUrl`: WebSocket URL
- `connectionTimeout`: 连接超时（毫秒）
- `receiveTimeout`: 接收超时（毫秒）
- `sendTimeout`: 发送超时（毫秒）

#### UI 配置 (ui)
- `defaultHorizontalPadding`: 默认水平内边距
- `defaultVerticalPadding`: 默认垂直内边距
- `defaultBorderRadius`: 默认圆角半径

### 代码中使用配置

```dart
import 'package:fastapp/constants/app_config.dart';

// 应用名称
Text(AppConfig.appName)

// 网络配置
final dio = Dio(BaseOptions(
  baseUrl: AppConfig.apiBaseUrl,
  connectTimeout: Duration(milliseconds: AppConfig.connectionTimeout),
));

// UI 配置
BorderRadius.circular(AppConfig.defaultBorderRadius)
```

## 三、主题配置

### 主题文件结构

主题配置独立于应用配置，便于扩展和维护。

#### config/themes/theme_config.json
```json
{
  "themes": ["light", "dark"],
  "default": "light"
}
```

#### config/themes/light.json
```json
{
  "id": "light",
  "name": "亮色",
  "seedColor": "#2196F3",
  "scaffoldBackground": "#FFFFFF",
  "button": {
    "background": "#424242",
    "foreground": "#FFFFFF",
    "disabledBackground": "#BDBDBD",
    "disabledForeground": "#B3FFFFFF"
  },
  "text": {
    "primary": "#212121",
    "secondary": "#757575",
    "hint": "#9E9E9E",
    "disabled": "#BDBDBD"
  },
  "border": {
    "default": "#E0E0E0",
    "focused": "#2196F3",
    "error": "#F44336"
  },
  "status": {
    "success": "#4CAF50",
    "error": "#F44336",

    "info": "#2196F3"
  },
  "background": {
    "card": "#FFFFFF",
    "input": "#F5F5F5"
  }

```

### 配置项说明

| 分类 | 配置项 | 说明 |
|------|--------|------|
| 基础 | `seedColor` | Material 3 种子颜色 |
| 基础 | `scaffoldBackground` | 页面背景色（可为 null） |
| 按钮 | `button.background` | 按钮背景色 |
| 按钮 | `button.foreground` | 按钮文字色 |
| 按钮 | `button.disabledBackground` | 禁用按钮背景色 |
| 按钮 | `button.disabledForeground` | 禁用按钮文字色 |
| 文字 | `text.primary` | 主要文字色 |
| 文字 | `text.secondary` | 次要文字色 |
| 文字 | `text.hint` | 提示文字色 |
| 边框 | `border.default` | 默认边框色 |
| 边框 | `border.focused` | 聚焦边框色 |
| 边框 | `border.error` | 错误边框色 |
| 状态 | `status.success` | 成功状态色 |
| 状态 | `status.error` | 错误状态色 |
| 状态 | `status.warning` | 警告状态色 |
| 背景 | `background.card` | 卡片背景色 |
| 背景 | `background.input` | 输入框背景色 |

### 使用主题

#### 异步加载（推荐）

```dart
import 'package:fastapp/constants/app_theme.dart';

// 应用启动时初始化
await ThemeConfigManager.loadThemeMetadata();

// 加载主题
final theme = await AppTheme.getThemeFromConfig(AppThemeType.light);
```

#### 同步获取（兼容模式）

```dart
// 如果主题已缓存，可以同步获取
final theme = AppTheme.getTheme(AppThemeType.light);
```

### 添加新主题

1. 创建新主题文件：`config/themes/ocean.json`
2. 更新 `theme_config.json`：
   ```json
   {
     "themes": ["light", "dark", "ocean"],
     "default": "light"
   }
   ```
3. 无需修改任何 Dart 代码

## 四、修改配置

### 修改应用配置

```bash
# 1. 编辑 app_config.json
vim app/app_config.json

# 2. 运行同步脚本
cd app
dart run scripts/sync_config.dart

# 3. 重启应用
flutter run
```

### 修改主题配置

```bash
# 1. 编辑主题文件
vim app/config/themes/light.json

# 2. 清除主题缓存并重启应用（无需同步脚本）
flutter run

# 或在应用中调用
AppTheme.clearCache();
```

### 配置同步目标

运行 `sync_config.dart` 会同步以下文件：

- ✅ `lib/constants/app_config.dart`
- ✅ `android/app/src/main/AndroidManifest.xml`
- ✅ `android/app/build.gradle`
- ✅ `ios/Runner/Info.plist`
- ✅ `macos/Runner/Configs/AppInfo.xcconfig`
- ✅ `web/index.html`
- ✅ `web/manifest.json`
- ⚠️ iOS `project.pbxproj`（需在 Xcode 手动管理）

## 六、最佳实践

### ✅ 推荐

1. **分离关注点**: 应用配置放 `app_config.json`，主题配置放 `config/themes/`
2. **使用主题默认**: 让组件自动使用主题定义的颜色
3. **统一管理**: 避免在代码中硬编码配置值
4. **同步后提交**: 生成的文件也需要提交到版本控制
5. **语义化命名**: 主题 ID 使用有意义的名称（如 `ocean`、`forest`）

### ❌ 避免

1. ❌ 手动修改 `app_config.dart`（会被覆盖）
2. ❌ 在代码中硬编码主题颜色
3. ❌ 修改 JSON 后忘记同步
4. ❌ 混淆应用配置和主题配置

## 七、常见问题

### Q1: 修改 JSON 后配置未生效？

运行同步脚本：
```bash
cd app && dart run scripts/sync_config.dart
```

### Q2: 可以直接修改 app_config.dart 吗？

**不可以！** 该文件由脚本自动生成，手动修改会被覆盖。

### Q3: 如何添加新配置项？

1. 在 `app_config.json` 添加字段
2. 在 `scripts/sync_config.dart` 添加同步规则
3. 在 `app_config.dart` 添加常量声明（作为模板）
4. 运行同步脚本

### Q4: 主题修改后未生效？

1. 检查 JSON 格式是否正确
2. 重启应用（热重载可能不够）
3. 调用 `AppTheme.clearCache()` 清除缓存

### Q5: 如何修改 Android 包名？

1. 修改 `app_config.json` 中的 `android.packageName`
2. 运行 `dart run scripts/sync_config.dart`
3. 包名自动同步到 AndroidManifest.xml 和 build.gradle

### Q6: 如何修改 iOS Bundle ID？

iOS Bundle ID 需在 Xcode 中手动修改，`app_config.json` 中的值仅用于记录。

## 八、架构优势

### 新架构特点

1. **职责清晰**: 应用配置与主题配置分离
2. **易于扩展**: 添加新主题只需创建 JSON 文件
3. **类型安全**: ThemeConfig 类提供类型检查
4. **无需重编译**: 主题配置可动态加载
5. **便于分享**: 主题文件可独立分发

### 配置对比

| 方面 | 旧架构 | 新架构 |
|------|--------|--------|
| 主题配置位置 | app_config.json | config/themes/*.json |
| 颜色常量 | app_colors.dart (冗余) | 已删除 |
| 扩展性 | 修改代码 | 添加 JSON 文件 |
| 职责分离 | 混合 | 清晰分离 |
