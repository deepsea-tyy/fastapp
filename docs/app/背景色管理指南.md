# 背景色管理指南

## 背景色层级体系

```
┌─────────────────────────────────────────┐
│  Scaffold (应用级背景 - 最底层)          │  ← scaffold
│  ┌───────────────────────────────────┐  │
│  │  Page (页面背景)                  │  │  ← page
│  │  ┌─────────────────────────────┐  │  │
│  │  │  Section (分区背景)         │  │  │  ← section
│  │  │  ┌───────────────────────┐  │  │  │
│  │  │  │  Card (卡片背景)      │  │  │  │  ← card
│  │  │  │  ┌─────────────────┐  │  │  │  │
│  │  │  │  │  Content       │  │  │  │  │
│  │  │  │  └─────────────────┘  │  │  │  │
│  │  │  └───────────────────────┘  │  │  │
│  │  └─────────────────────────────┘  │  │
│  └───────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

## 主题配置

### Light 主题
```json
{
  "background": {
    "scaffold": "#FFFFFF",
    "page": "#F5F5F5",
    "card": "#FFFFFF",
    "section": "#FAFAFA",
    "input": "#F5F5F5",
    "dialog": "#FFFFFF",
    "bottomSheet": "#FFFFFF",
    "elevated": "#FFFFFF"
  }
}
```

### Dark 主题
```json
{
  "background": {
    "scaffold": null,
    "page": "#121212",
    "card": "#1E1E1E",
    "section": "#2C2C2C",
    "input": "#2C2C2C",
    "dialog": "#1E1E1E",
    "bottomSheet": "#1E1E1E",
    "elevated": "#2C2C2C"
  }
}
```

## 使用方法（推荐）

### 1. 标准 Material 组件（自动应用主题）

```dart
import 'package:flutter/material.dart';

class MyPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      // Scaffold 背景自动使用主题配置
      body: ListView(
        padding: EdgeInsets.all(16),
        children: [
          // Card 自动使用主题的卡片背景色
          Card(
            child: Padding(
              padding: EdgeInsets.all(16),
              child: Text('卡片内容'),
            ),
          ),

          SizedBox(height: 16),

          // TextField 自动使用主题的输入框背景色
          TextField(
            decoration: InputDecoration(
              filled: true,
              hintText: '请输入内容',
            ),
          ),
        ],
      ),
    );
  }
}
```

### 2. 自定义组件（使用 AppBackgrounds）

```dart
import 'package:fastapp/constants/app_backgrounds.dart';

class MyCustomPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final backgrounds = AppBackgrounds.of(context);

    return Scaffold(
      body: Container(
        // 页面背景
        color: backgrounds.page,
        child: Column(
          children: [
            // 分区背景
            Container(
              color: backgrounds.section,
              padding: EdgeInsets.all(16),
              child: Text('分区内容'),
            ),

            // 卡片背景
            Container(
              color: backgrounds.card,
              padding: EdgeInsets.all(16),
              margin: EdgeInsets.all(16),
              child: Text('卡片内容'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## 使用建议

### Scaffold 背景（应用级）
```dart
Scaffold()  // 自动使用主题配置
```

### Page 背景（页面级）
```dart
Container(
  color: AppBackgrounds.of(context).page,
  child: PageContent(),
)
```

### Section 背景（分区级）
```dart
Container(
  color: AppBackgrounds.of(context).section,
  child: SectionContent(),
)
```

### Card 背景（卡片级）
```dart
// 推荐：使用 Card 组件
Card(child: CardContent())

// 或自定义容器
Container(
  color: AppBackgrounds.of(context).card,
  child: CardContent(),
)
```

### Input 背景（输入框）
```dart
TextField(
  decoration: InputDecoration(
    filled: true,  // 启用填充，自动使用主题配置
    hintText: '请输入',
  ),
)
```

### Dialog 背景（对话框）
```dart
showDialog(
  context: context,
  builder: (context) => AlertDialog(
    // 自动使用主题的 dialogBackgroundColor
    title: Text('标题'),
    content: Text('内容'),
  ),
)
```

### BottomSheet 背景（底部弹窗）
```dart
showModalBottomSheet(
  context: context,
  builder: (context) => Container(
    // 自动使用主题的 bottomSheetBackgroundColor
    child: BottomSheetContent(),
  ),
)
```

## 完整示例

```dart
import 'package:flutter/material.dart';
import 'package:fastapp/constants/app_backgrounds.dart';

class ExamplePage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final backgrounds = AppBackgrounds.of(context);

    return Scaffold(
      appBar: AppBar(title: Text('背景色示例')),
      body: Container(
        color: backgrounds.page,
        child: ListView(
          padding: EdgeInsets.all(16),
          children: [
            // 分区
            Container(
              color: backgrounds.section,
              padding: EdgeInsets.all(16),
              margin: EdgeInsets.only(bottom: 16),
              child: Column(
                children: [
                  Text('用户信息', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
                  SizedBox(height: 12),

                  // 卡片
                  Card(
                    child: Padding(
                      padding: EdgeInsets.all(12),
                      child: Text('用户名: 张三'),
                    ),
                  ),
                ],
              ),
            ),

            // 输入框
            TextField(
              decoration: InputDecoration(
                filled: true,
                hintText: '请输入内容',
                prefixIcon: Icon(Icons.search),
              ),
            ),

            SizedBox(height: 16),

            // 对话框按钮
            ElevatedButton(
              onPressed: () {
                showDialog(
                  context: context,
                  builder: (context) => AlertDialog(
                    title: Text('提示'),
                    content: Text('这是一个对话框'),
                    actions: [
                      TextButton(
                        onPressed: () => Navigator.pop(context),
                        child: Text('确定'),
                      ),
                    ],
                  ),
                );
              },
              child: Text('显示对话框'),
            ),

            // 底部弹窗按钮
            ElevatedButton(
              onPressed: () {
                showModalBottomSheet(
                  context: context,
                  builder: (context) => Container(
                    padding: EdgeInsets.all(16),
                    child: Column(
                      mainAxisSize: MainAxisSize.min,
                      children: [
                        ListTile(
                          leading: Icon(Icons.share),
                          title: Text('分享'),
                          onTap: () => Navigator.pop(context),
                        ),
                      ],
                    ),
                  ),
                );
              },
              child: Text('显示底部弹窗'),
            ),
          ],
        ),
      ),
    );
  }
}
```

## 最佳实践

### ✅ 推荐做法

1. **优先使用标准组件**
   ```dart
   // ✅ 好 - 自动应用主题
   Card(child: Text('内容'))
   TextField(decoration: InputDecoration(filled: true))
   ```

2. **自定义组件使用 AppBackgrounds**
   ```dart
   // ✅ 好 - 使用主题配置
   Container(
     color: AppBackgrounds.of(context).page,
     child: Content(),
   )
   ```

3. **保持层级清晰**
   ```
   Scaffold → Page → Section → Card → Content
   ```

### ❌ 避免

- ❌ 硬编码颜色值
- ❌ 在多个地方重复定义相同背景色
- ❌ 不考虑暗色主题
- ❌ 背景层级混乱

## 常见问题

### Q: 如何修改背景色？

修改 `config/themes/light.json` 或 `dark.json`：
```json
{
  "background": {
    "page": "#F0F0F0"
  }
}
```

重启应用即可生效。

### Q: page vs section 的区别？

- `page`: 整个页面的背景
- `section`: 页面内的分区或模块
