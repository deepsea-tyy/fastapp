# Scripts 脚本快速指南

Flutter 项目开发、构建和维护脚本工具集。

## 📋 核心脚本

### 🚀 日常开发

#### `dev.sh` - 快速运行
自动检测设备并启动应用，支持智能修复连接问题。

```bash
./scripts/dev.sh                    # 自动检测设备运行
./scripts/dev.sh emulator-5554      # 指定设备
./scripts/dev.sh --release          # Release 模式
```

---

### 🧹 清理构建

#### `clean.sh` - 清理缓存
```bash
./scripts/clean.sh quick    # 快速清理（推荐，解决 MobX 等问题）
./scripts/clean.sh          # 彻底清理（所有平台缓存）
```

清理内容：Flutter 缓存、MobX 生成代码、Android Gradle、iOS Pods、各平台构建文件

#### `rebuild.sh` - 重建平台
```bash
./scripts/rebuild.sh ios        # 重建 iOS（CocoaPods 问题）
./scripts/rebuild.sh android    # 重建 Android（Gradle 问题）
./scripts/rebuild.sh            # 重建所有平台
```

---

### 🔧 设备工具

#### `fix_emulator.sh` - 修复模拟器
```bash
./scripts/fix_emulator.sh                   # 修复连接
./scripts/fix_emulator.sh Pixel_9_Pro_XL    # 修复并启动
```

---

### 🎨 资源配置

#### `launch_screen.dart` - 图标和启动图
```bash
dart run scripts/launch_screen.dart         # 生成所有
dart run scripts/launch_screen.dart icons   # 仅图标
dart run scripts/launch_screen.dart launch  # 仅启动图
```

生成平台：Android（mipmap/drawable）、iOS（AppIcon/LaunchImage）、Web（favicon）

#### `sync_config.dart` - 同步配置
```bash
dart run scripts/sync_config.dart
```

同步 `app_config.json` 配置到：AndroidManifest.xml、Info.plist、index.html 等平台配置文件

## 🔄 典型场景

### 构建问题
```bash
./scripts/clean.sh quick              # 首选：快速修复 MobX/依赖问题
./scripts/clean.sh                    # 完整清理
./scripts/rebuild.sh ios|android      # 平台特定重建
```

### 设备连接
```bash
flutter devices                       # 检查设备
./scripts/fix_emulator.sh            # 修复 Android 模拟器
./scripts/fix_emulator.sh <AVD名称>   # 启动模拟器
./scripts/dev.sh                      # 运行应用
```

### 配置更新
```bash
# 编辑 app_config.json
dart run scripts/sync_config.dart           # 同步配置
dart run scripts/launch_screen.dart         # 生成资源
./scripts/dev.sh                            # 验证效果
```

## 🆘 问题速查

| 问题 | 解决方案 |
|------|---------|
| MobX 代码生成错误 | `./scripts/clean.sh quick` |
| CocoaPods 失败 | `./scripts/rebuild.sh ios` |
| Gradle 同步失败 | `./scripts/rebuild.sh android` |
| 模拟器 offline | `./scripts/fix_emulator.sh` |
| 切换 Flutter 版本后 | `./scripts/clean.sh` + `flutter doctor` |

---

## 📌 提示

- **日常使用**：`dev.sh` 启动应用，`clean.sh quick` 解决问题
- **定期维护**：切换分支或每周运行 `clean.sh` 完整清理
- **配置管理**：修改 `app_config.json` 后记得运行 `sync_config.dart`
- **详细文档**：查看 `app/scripts/README.md` 获取完整说明
