# 开发指南

> FastApp Flutter 移动端应用开发指南

## 项目简介

使用 MobX 和 Provider 的 Flutter 项目，采用分层架构设计。

**主要功能**：登录/首页/路由、主题切换、多语言、网络请求、本地存储、状态管理、依赖注入

## 开发环境

### 版本要求

| 环境 | 版本 |
|------|------|
| Flutter SDK | 3.38.3 (stable) |
| Dart SDK | 3.10.1 |
| Xcode | 15.4+ (macOS) |
| iOS 最低版本 | 13.0 |
| CocoaPods | 1.16.2+ |
| Android SDK | 36 (API 36) |
| Java | 11 |

### 环境安装

**系统要求**：macOS 10.14+ / Windows 10+ / Ubuntu 18.04+

**安装步骤**：

1. **安装 Flutter SDK**
   ```bash
   # macOS
   brew install --cask flutter
   # 或访问 https://flutter.dev/docs/get-started/install
   ```

2. **配置环境变量**
   ```bash
   export PATH="$PATH:[PATH_TO_FLUTTER]/flutter/bin"
   ```

3. **安装开发工具**
   - Android Studio（Android 开发）
   - Xcode 15.4+（iOS 开发，仅 macOS）
   - VS Code（推荐安装 Flutter 和 Dart 插件）

4. **检查环境**
   ```bash
   flutter doctor
   ```

### 平台配置

**Android**：
- 安装 Android SDK（API 36+）
- 配置 Java 11
- 运行 `flutter doctor --android-licenses`
- Gradle 8.11.1 / AGP 8.9.1 / NDK 29.0.14206865（已配置）

**iOS (macOS)**：
- 安装 Xcode 15.4+
- 安装 CocoaPods：`sudo gem install cocoapods`
- 运行 `cd ios && pod install`

## 快速开始

### 1. 安装依赖

```bash
cd app
flutter pub get
```

### 2. 生成代码

```bash
flutter gen-l10n  # 生成本地化文件
flutter packages pub run build_runner build --delete-conflicting-outputs  # 生成 MobX 代码
```

### 3. 启动模拟器

```bash
# iOS
flutter emulators --launch apple_ios_simulator
# 或
open -a Simulator

# Android
flutter emulators  # 查看可用模拟器列表
flutter emulators --launch <emulator_id>  # 启动指定模拟器
```

### 4. 运行应用

```bash
flutter devices        # 查看设备
flutter run            # 自动选择设备
flutter run -d ios     # 指定 iOS
flutter run -d android # 指定 Android
flutter run -d chrome     # Web
flutter run -d macos      # macOS
```

**热重载**：运行后按 `r` 热重载，按 `R` 热重启，按 `q` 退出

## 添加新功能

### 添加新界面

1. 在 `presentation/views/` 创建目录和文件
2. 创建 Store（使用 MobX）
3. 注册路由（`utils/routes/routes.dart`）
4. 注册 Store（`presentation/di/module/store_module.dart`）
5. 运行代码生成：`flutter packages pub run build_runner build --delete-conflicting-outputs`

### 添加业务功能

遵循分层架构：
1. 创建实体（`domain/entity/`）
2. 定义仓库接口（`domain/repository/`）
3. 实现仓库（`data/repository/`）
4. 创建用例（`domain/usecase/`）
5. 注册依赖（DI 模块）
6. 创建界面和 Store

## 状态管理（MobX）

**定义 Store**：
```dart
import 'package:mobx/mobx.dart';
part 'example_store.g.dart';

class ExampleStore = _ExampleStore with _$ExampleStore;

abstract class _ExampleStore with Store {
  @observable bool isLoading = false;
  
  @action
  Future<void> loadData() async {
    isLoading = true;
    // 业务逻辑
    isLoading = false;
  }
}
```

**在 UI 中使用**：
```dart
import 'package:flutter_mobx/flutter_mobx.dart';

Observer(builder: (_) => Text(_store.data))
```
