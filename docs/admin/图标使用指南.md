# 图标使用指南

## 一、图标组件 (ma-svg-icon)

### 基础使用

支持三种图标类型：**Iconify 图标**、**UnoCSS 图标**、**自定义 SVG 图标**。

```vue
<!-- Iconify 图标 -->
<ma-svg-icon name="mdi:account" :size="20" />

<!-- UnoCSS 图标 -->
<ma-svg-icon name="i-carbon:user" :size="24" />

<!-- 自定义 SVG 图标 -->
<ma-svg-icon name="custom-icon" :size="16" />
```

### 组件属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `name` | `string` | 图标名称（必填） |
| `size` | `string \| number` | 图标大小（如 `20` 或 `'20px'`） |
| `color` | `string` | 图标颜色（CSS 颜色值） |
| `flip` | `'horizontal' \| 'vertical' \| 'both'` | 图标翻转方向 |
| `rotate` | `number` | 图标旋转角度（0-360） |

## 二、图标类型

### Iconify 图标

**格式**：`前缀:图标名`，如 `mdi:account`、`ep:home-filled`

**常用图标集**：
- `mdi` - Material Design Icons（5000+）
- `ant-design` - Ant Design Icons（800+）
- `ep` - Element Plus Icons（300+）
- `heroicons` - Heroicons（1200+）

**查找图标**：[Iconify 图标库](https://icon-sets.iconify.design/)

### UnoCSS 图标

**格式**：`i-前缀:图标名`，如 `i-carbon:user`

编译时优化，性能最佳，支持类名直接使用：
```html
<i class="i-carbon:user text-2xl"></i>
```

### 自定义 SVG 图标

**位置**：`admin/src/assets/icons/`

将 SVG 文件放入目录，使用文件名作为图标名（不含扩展名）。

## 三、图标选择器 (ma-icon-picker)

提供可视化图标选择功能，支持搜索、分类浏览、自定义图标。

```vue
<ma-icon-picker v-model="iconName" />
```

## 四、离线图标配置

### 运行生成脚本

```bash
cd admin
pnpm run gen:icons
```

脚本会交互提示：
1. 选择需要的图标集（支持多选，默认选中上次选择的图标集）
2. 是否开启离线模式（默认 `Y`）

### 生成的文件

```
admin/src/iconify/
├── index.json      # 用户配置（collections + isOfflineUse）
└── data.json       # 图标集元数据（用于选择器）

admin/public/icons/
└── *-raw.json      # 完整图标数据（用于离线渲染）
```

### 应用初始化

在应用入口（如 `main.ts`）中预加载离线数据：

```typescript
import { icons, downloadAndInstall } from '@/iconify'

async function initIcons() {
  for (const item of icons) {
    await downloadAndInstall(item.prefix)
  }
}

initIcons()
```

### 配置说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `collections` | `string[]` | 选中的图标集前缀列表 |
| `isOfflineUse` | `boolean` | 是否离线使用（`true` 则生成 `-raw.json`） |

## 五、工作原理

```
开发阶段：pnpm run gen:icons → 选择图标集 → 生成离线数据
运行阶段：main.ts initIcons() → 加载 public/icons/* → addCollection 注入
渲染阶段：Icon 组件从本地缓存读取，不再请求网络
```

## 六、注意事项

1. **执行时机**：`gen:icons` 只需执行一次，图标集变更时重新执行
2. **体积影响**：每个图标集的 `-raw.json` 文件较大，建议只选择需要的图标集
3. **构建部署**：`public/icons/*` 会被 Vite 自动复制到 `dist/icons/`
4. **版本同步**：更新 `@iconify/json` 后建议重新运行脚本
