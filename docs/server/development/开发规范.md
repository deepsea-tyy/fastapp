# 开发规范指南

## 1. 代码分层架构

```
Controller → Service → Repository → Model
    ↓           ↓          ↓         ↓
   HTTP      业务逻辑    数据操作   数据模型
```

## 2. 控制器开发规范

### 控制器职责

- 数据验证（FormRequest）
- 数据准备和格式化
- 用户信息传入（`created_by`、`updated_by`）
- 调用服务层
- 返回统一响应格式

⚠️ **重要**：控制器只负责数据验证、准备和传递，不包含业务逻辑。

### Admin 和 Api 控制器区别

| 类型 | 路由前缀 | 场景 | 认证方式 | 中间件配置 |
|------|---------|------|---------|-----------|
| **Api** | `/api/模块/功能` | 移动端/前端API | JWT Token | 方法级别 |
| **Admin** | `/admin/模块/功能` | 后台管理 | AccessToken + Permission（类级别）+ Operation（方法级别） | 混合配置 |

### 控制器示例

#### Admin 控制器示例

```php
use App\Http\Admin\Controller\AbstractController;
use App\Common\Middleware\AccessTokenMiddleware;
use App\Common\Middleware\OperationMiddleware;
use App\Http\Admin\Middleware\PermissionMiddleware;
use App\Http\Admin\Permission;
use App\Http\CurrentUser;
use Hyperf\HttpServer\Annotation\Controller;
use Hyperf\HttpServer\Annotation\DeleteMapping;
use Hyperf\HttpServer\Annotation\GetMapping;
use Hyperf\HttpServer\Annotation\Middleware;
use Hyperf\HttpServer\Annotation\PostMapping;
use Hyperf\HttpServer\Annotation\PutMapping;

#[Controller]
#[Middleware(middleware: AccessTokenMiddleware::class, priority: 100)]
#[Middleware(middleware: PermissionMiddleware::class, priority: 99)]
class ArticleController extends AbstractController
{
    public function __construct(
        protected readonly ArticleService $service,
        protected readonly CurrentUser $currentUser
    ) {}

    #[GetMapping(path: '/admin/article/article/list')]
    #[Permission(code: 'article:article:list')]
    public function pageList(): Result
    {
        return $this->success($this->service->page(
            $this->getRequestData(),
            $this->getCurrentPage(),
            $this->getPageSize()
        ));
    }

    #[PostMapping(path: '/admin/article/article/create')]
    #[Permission(code: 'article:article:create')]
    #[Middleware(middleware: OperationMiddleware::class, priority: 98)]
    public function create(ArticleRequest $request): Result
    {
        $this->service->create(array_merge($request->validated(), [
            'created_by' => $this->currentUser->id(),
        ]));
        return $this->success();
    }

    #[PutMapping(path: '/admin/article/article/save/{id}')]
    #[Permission(code: 'article:article:save')]
    #[Middleware(middleware: OperationMiddleware::class, priority: 98)]
    public function save(int $id, ArticleRequest $request): Result
    {
        $this->service->updateById($id, array_merge($request->validated(), [
            'updated_by' => $this->currentUser->id(),
        ]));
        return $this->success();
    }

    #[DeleteMapping(path: '/admin/article/article/delete')]
    #[Permission(code: 'article:article:delete')]
    #[Middleware(middleware: OperationMiddleware::class, priority: 98)]
    public function delete(): Result
    {
        $this->service->deleteById($this->getRequestData(), []);
        return $this->success();
    }
}
```

**中间件配置**：
- 类级别：`AccessTokenMiddleware` + `PermissionMiddleware`（所有方法）
- 方法级别：`OperationMiddleware`（仅新增、修改、删除方法，用于操作日志）

#### Api 控制器示例

```php
use App\Common\AbstractController;
use App\Common\Middleware\TokenMiddleware;
use App\Common\Result;
use App\Http\CurrentUser;
use Hyperf\HttpServer\Annotation\Middleware;
use Hyperf\Swagger\Annotation as OA;

class UserController extends AbstractController
{
    public function __construct(
        private readonly CurrentUser $currentUser,
    ) {}

    #[OA\Post(path: '/api/user/register', summary: '用户注册', tags: ['用户接口'])]
    public function register(UserRequest $request): Result
    {
        $this->UserService->register($request->validated());
        return $this->success([], '注册成功');
    }

    #[OA\Get(path: '/api/user/info', summary: '获取用户信息', tags: ['用户接口'])]
    #[Middleware(TokenMiddleware::class)]
    public function info(): Result
    {
        return $this->success($this->currentUser->user());
    }
}
```

## 3. 服务层规范

### 服务层职责

- 业务逻辑处理
- 数据流转（调用 Repository）
- 业务规则验证（非数据格式验证）

⚠️ **重要**：服务层不做数据验证，数据验证由控制器层的 FormRequest 完成。

### 服务层示例

```php
class UserService extends IService
{
    public function __construct(protected UserRepository $repository) {}
    
    public function getList(array $params): Collection
    {
        return $this->repository->list($params);
    }
}
```

## 4. 数据仓库规范

### IRepository 自动搜索功能

根据数据库字段类型和模型 `casts` 自动匹配查询条件：

| 字段类型 | 查询方式 |
|---------|---------|
| 整数/浮点 | `where($field, $value)` |
| 日期时间 | 范围查询：`[start, end]` 或 `"start~end"`，自动添加时间部分 |
| JSON | `whereJsonContains($field, $value)` |
| 布尔 | `where($field, (bool)$value)` |
| 字符串 | `where($field, 'like', "%{$value}%")` |
| 数组值 | `whereIn($field, $value)` |

**自动跳过**：`page`, `per_page`, `order_by`, `order_by_direction`, `order`, `sort`

### handleSearch 方法规范

**基本使用**：无需特殊处理时，直接使用父类自动搜索，无需重写。

**自定义搜索逻辑**（关联查询、数据权限、预加载等）：

```php
public function handleSearch(Builder $query, array $params): Builder
{
    // 1. 处理数据权限（如果需要）
    if (Arr::has($params, 'created_by')) {
        DataScopeTool::applyUserDataScope($params['created_by'], $query);
        unset($params['created_by']);
    }
    
    // 2. 处理关联查询（如果需要）
    if (Arr::has($params, 'phone')) {
        $query->whereHas('adminSetting', static function (Builder $q) use ($params) {
            $q->where('phone', 'like', Arr::get($params, 'phone') . '%');
        });
        unset($params['phone']);
    }
    
    // 3. 预加载关联关系
    $query->with(['profile', 'adminSetting']);
    
    // 4. ⚠️ 必须调用父类方法
    return parent::handleSearch($query, $params);
}
```

**重要规则**：
1. 移除已处理参数：`unset($params['key'])`
2. 必须调用父类方法：`parent::handleSearch($query, $params)`
3. 处理顺序：特殊逻辑 → 预加载关联 → 调用父类方法

**常见错误**：
- ❌ 未 `unset` 参数或未调用 `parent::handleSearch()`

### deleteById 方法说明

```php
public function deleteById(mixed $id, array $where = []): int
```

**参数**：
- `$id`: 要删除的ID（支持单个或数组），通常使用 `$this->getRequestData()` 获取
- `$where`: 额外的where条件（可选），用于数据权限过滤等

**使用场景**：
- 数据权限：`deleteById($this->getRequestData(), ['created_by' => $userId])`
- 状态过滤：`deleteById($this->getRequestData(), ['status' => 1])`

**请求格式**：✅ `[1, 2, 3]` | ❌ `{"ids": [1, 2, 3]}`

## 5. 请求验证规范

### ActionRulesTrait 方式（推荐）

```php
use App\Common\Request\Traits\ActionRulesTrait;

class UserRequest extends FormRequest
{
    use ActionRulesTrait;

    // 通用规则（所有方法都会应用）
    public function commonRules(): array
    {
        return [
            'username' => 'string|max:16',
            'password' => 'string|max:32',
        ];
    }

    // 自动匹配 create 方法
    public function createRules(): array
    {
        return [
            'username' => 'required|string|max:16',
            'password' => 'required|string|max:32',
        ];
    }

    // 自动匹配 save/update 方法
    public function saveRules(): array
    {
        return [
            'username' => 'sometimes|string|max:16',
        ];
    }
}
```

### scene 方式（复杂场景）

```php
class UserRequest extends FormRequest
{
    protected array $scenes = [
        'register' => ['username' => 'required', 'password' => 'required|confirmed'],
        'login' => ['username' => 'required', 'password' => 'required'],
    ];
}

// 使用：$request->scene('register')->validated();
```

## 6. 数据模型规范

### Model 基本结构

```php
use Hyperf\DbConnection\Model\Model;

/**
 * 用户模型
 * @property int $id ID
 * @property string $username 用户名
 * @property \Carbon\Carbon $created_at 创建时间
 */
class User extends Model
{
    protected ?string $table = 'user';
    protected array $fillable = ['username', 'email'];
    protected array $casts = ['id' => 'integer', 'created_at' => 'datetime'];
    protected array $hidden = ['password'];
}
```

### Model 类型声明说明

⚠️ **重要**：代码生成器生成的Model只有PHPDoc注释（`@property`），没有类属性类型声明。

- **PHPDoc注释**：代码生成器自动生成，IDE可正常提示
- **类属性类型声明**：需手动添加（PHP 8.0+），用于更强的类型检查

## 7. 命名规范

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| **文件命名** | 大驼峰命名法 | `UserController.php`, `UserService.php` |
| **方法命名** | 小驼峰命名法 | `getList()`, `create()`, `delete()` |
| **变量命名** | 小驼峰命名法 | `$userId`, `$userName` |

## 8. 代码风格

### 注释规范

类和方法应添加注释说明功能和用途。

### 异常处理

```php
try {
    $result = $this->service->process($data);
} catch (BusinessException $e) {
    return $this->error($e->getMessage());
} catch (\Exception $e) {
    Log::error('处理失败', ['error' => $e->getMessage()]);
    return $this->error('系统错误');
}
```
