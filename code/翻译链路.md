# 编码文档：翻译链路（字典 + i18n locale + MaDictSelect）

> 本文档为具体代码链路分析，用于快速定位代码，避免重复检索消耗 token。
>
> 范围：字典定义 → 运行时注册 → MaDictSelect 渲染 → 标签/展示翻译 → locale 文件。

## 2. i18n 使用规范（两种场景，两种方式）

### 方式 A：Vue 组件 / Store setup 上下文 → `useI18n()`

**有 `<i18n>` 局部翻译块的组件：**
```ts
import { useI18n } from 'vue-i18n'
const { t } = useI18n({ useScope: 'local' })  // 优先查局部，再 fallback 到全局
```

**无局部 i18n 的组件 / Store：**
```ts
import { useI18n } from 'vue-i18n'
const { t } = useI18n()  // 全局 scope
```

> **判断依据**：文件顶部是否有 `<i18n lang="yaml">` 块。有则必须用 `useScope: 'local'`，否则局部翻译不生效。

### 方式 B：普通 .ts 文件 / 非 setup 上下文 → `@/utils/i18n.ts`

```ts
import { t, te, setLocale, getLocale } from '@/utils/i18n.ts'

// 直接调用（非响应式，用于工具函数等一次性场景）
const label = t('some.key')
```

`@/utils/i18n.ts` 还提供响应式 composable（用于 store setup 等场景）：
```ts
import { useI18nGlobal } from '@/utils/i18n.ts'

const { t, locale } = useI18nGlobal()  // 响应式 t，语言切换自动更新
```

### 已废弃：`useTrans`

`src/hooks/auto-imports/useTrans.ts` 的 `useTrans()` 已废弃，不再使用。
- `useTrans().globalTrans` → 替换为 `useI18n().t`
- `useTrans().localTrans` → 替换为 `useI18n({ useScope: 'local' }).t`

## 3. Dictionary 条目三字段

字典项结构（所有 `story-*.ts` 一致）：

```ts
{
  label: '对白',                        // 默认中文标签（i18n 取不到时回退）
  value: 'speech',                     // 真正的 value，v-model 绑定、API 存储
  i18n: 'storyStudio.mount.source.speech',  // 对应 locale YAML 的 key 路径
}
```

- `value`：**业务唯一真实值**，进入 type filter、API payload、DB 存储，永不翻译
- `label`：兜底硬编码中文标签，仅在 i18n 翻译不可用时显示
- `i18n`：vue-i18n 翻译 key，走 `.yaml` 中对应路径

### MaDictSelect 的标签渲染优先级

```ts
// translatedOptions computed 内部预计算
const label = item.i18n ? t(item.i18n) : item.label
```

**有 `i18n` → 走 vue-i18n locale 翻译；无 → 直接用硬编码 `label`。**
此规则同时适用于 `el-option-group` 的 group label 和 group 内 `sub` 项。

> **响应式说明**：翻译在 `translatedOptions` computed 中完成，`t()` 在 computed 内部被调用，locale 变化时 computed 自动重算 → 视图更新。

### MaDictSelect 取值

```vue
<el-option :value="item.value" :label="item._label">
```

`v-model` / `emit('update:modelValue', ...)` 始终绑定/发射 **`item.value`**（字符串/原始值），与 locale/翻译完全无关。

## 4. 字典注册链路（启动加载流程）

```
启动 bootstrap
  → initProvider() 遍历 admin/src/provider/**/index.ts
    → provider/dictionary/index.ts.init()
      → import.meta.glob 扫描 3 个 glob 模式：
         ./data/**.{ts,js}                          （系统级字典）
         ../../plugins/*/*/dictionary/**.{ts,js}   （插件级字典 —— story-* 走这条）
         ../../modules/**/dictionary/**.{ts,js}    （业务模块级字典）
      → 字典文件名正则提取作为 dictName
         正则：/(data|plugins\/.*\/dictionary|modules\/.*\/dictionary)\/(.*)\.(ts|js)/ → $2
         例：plugins/ds/storyStudio/dictionary/story-frame-mount-source.ts → name = "story-frame-mount-source"
      → dictionary[name] = module.default
    → setProvider：app.config.globalProperties.$dictionary = dictionary

  → otherWorker()（bootstrap L84-L89）
    → Object.entries($dictionary).map(([name, data]) => dictStore.push(name, data))
    → Pinia dictMap.value.set(name, data) 完成注册
```

dictStore.push(name, data, replace=false)（useDictStore.ts L13-L25）：
- 首次 push → `set` 并返回 true
- 已存在 + `replace=true` → 覆盖并返回 true
- 已存在 + `replace=false` → **跳过**（返回 false），保证后注册不覆盖先注册

## 5. 两种"查字典"方式（MaDictSelect 查 / labels.ts 查）

### 方式 A：MaDictSelect（下拉组件 UI，走 i18n）

```vue
<MaDictSelect
  v-model="selectedType"
  dict-name="story-frame-mount-source"
  filterable
  size="small"
  clearable
  placeholder="全部类型"
/>
```

**内部流程（ma-dict-select.vue）：**
1. `dictStore = useDictStore()` → `sourceData = dictStore.find(dictName)` 拿到 Dictionary[]
2. `const { t } = useI18n()` → 全局翻译函数
3. `translatedOptions = computed(() => list.map(item => ({ ...item, _label: t(item.i18n) })))`
   - 翻译在 computed 中预计算，确保语言切换时响应式更新
4. v-for 每个 item → `:value="item.value"`（发射原值），`:label="item._label"`（预翻译结果）
5. `$attrs` 透传 `filterable` / `size` / `clearable` / `placeholder` 到底层 `el-select`

### 方式 B：labels.ts / 普通代码（离线取 label，不走 i18n）

```ts
function frameMountSourceLabel(source: FrameMountSource): string {
  return useDictStore().t('story-frame-mount-source', source) ?? source
}
```

`dictStore.t(name, value, attrName='label')`（useDictStore.ts L48-L62）：
1. `find(name)` 拿 Dictionary[]，字典未加载 → return `null`
2. `data.find(item => item.value == value)` 找到项（`==` 宽松比较），找不到 → return `null`
3. return `dictItem[attrName]`（默认就是字典的 `label` 字段，**不是 i18n**）

**这是"离线翻译"**：只读字典硬编码的 `label`，不依赖 i18n locale。

> 为什么用 `?? value` 回退？
> - 字典注册是异步的（provider init 阶段），组件 `onMounted` 前可能未加载完成
> - value 拼错、字典漏项、dictName 写错 等静默错误也给出可展示字符串而非 null

两种方式的区别总结：

| | MaDictSelect 下拉渲染 | labels.ts `dictStore.t()` |
| --- | --- | --- |
| 取翻译的方式 | `useI18n().t(item.i18n) ?? item.label`（computed 预计算，响应式） | `dictStore.find(name)` → 取 `item.label`（attrName 默认） |
| 多语言 | ✅ 随 locale 切换切换 | ❌ 始终显示 label 原文（中文） |
| dictMap 未加载时 | 不渲染选项（空下拉） | 返回 null → 用 `?? value` 回退 |

## 6. i18n locale 链路

### 6.1 Vue I18n 注入

admin/src/bootstrap.ts：

```
createI18nInstance(locale)  ←  @/utils/i18n.ts
  ↓
messages = @intlify/unplugin-vue-i18n/messages
  ↓ 插件打包时合并所有 locale YAML
vue-i18n createI18n({
  legacy: false,
  fallbackLocale: 'zh_CN',
  locale: useUserStore().getLanguage(),
  messages,
  globalInjection: true,
})
  ↓
app.use(i18n)
  ↓
组件内: const { t } = useI18n()
普通ts: import { t } from '@/utils/i18n.ts'
```

### 6.2 语言切换链路

```
用户点击语言切换（translate.tsx）
  → userStore.setLanguage(locale)
      → cache.set('language', locale)
      → setLocale(locale)  ← @/utils/i18n.ts，更新全局 i18n 实例
  → locale.value = locale  ← 组件内 useI18n 的 locale ref
  → 所有使用 t() 的 computed / 模板自动更新
```

> `userStore.setLanguage()` 内部会调用 `setLocale()` 同步全局 i18n 实例，确保 store 和 i18n 一致。

### 6.3 locale 文件结构

文件命名规范：`<lang_code>[<lang_label>].yaml`，bootstrap 正则提取（L34-L36）：
```
/\/locales\/(\w+)\[([^[\]]+)\]\.yaml$/
   $1 = value （locale code），例：zh_CN
   $2 = label （展示名），例：简体中文
```

### 6.4 storyStudio 翻译树

```yaml
storyStudio:
  mount:
    source:
      speech:      对白 / 對白 / セリフ / Dialogue   （i18n key: storyStudio.mount.source.speech）
      background:  背景
      material:    素材
      resource:    资源
      weather:     天气
      text:        文字
      stroke:      划线 / 劃線 / 書き込み / Stroke
      window:      窗口 / 視窗 / ウィンドウ / Window
  speech:
    intensityLevel: ...
    pitch: ...
  voice:
    field.lang / field.type / field.role: ...
    previewTitle: ...
    ...
```

对应字典项 `i18n` 键：`story-frame-mount-source.ts` 中 `i18n: 'storyStudio.mount.source.speech'` 等。

### 6.5 新增翻译的 5 处同步点（必须全部改，否则某语言/某端缺失）

> 翻译必须同步改 **4 个 locale × 2 份副本**，共 8 处。

（1）server/plugin/ds/storyStudio/web/locales/zh_CN[简体中文].yaml
（2）server/plugin/ds/storyStudio/web/locales/zh_TW[繁體中文].yaml
（3）server/plugin/ds/storyStudio/web/locales/ja[日本語].yaml
（4）server/plugin/ds/storyStudio/web/locales/en[English].yaml
（5）admin/src/plugins/ds/storyStudio/locales/zh_CN[简体中文].yaml
（6）admin/src/plugins/ds/storyStudio/locales/zh_TW[繁體中文].yaml
（7）admin/src/plugins/ds/storyStudio/locales/ja[日本語].yaml
（8）admin/src/plugins/ds/storyStudio/locales/en[English].yaml

**编辑约定：只改 (1)-(4)（server/ 那份），(5)-(8) 通过构建流程同步。**

### 6.6 新增字典 + 翻译的完整同步清单

```
1. server/.../web/dictionary/story-xxx.ts
      └─ 定义 { label, value, i18n:'storyStudio.xxx.yyy' }[]
```

## 7. 完整示例：DockFrameCol 类型筛选下拉的端到端链路

**目标**：用户点击 MaDictSelect → 选择「天气」→ 列表只显示 weather 类型的挂载项，且标签正确翻译。

### Step 1：字典启动加载

```
Provider dict init
  → import.meta.glob 读 story-frame-mount-source.ts 得到 8 项
  → name = "story-frame-mount-source"
  → $dictionary["story-frame-mount-source"] = [...8 项 Dictionary...]
bootstrap otherWorker()
  → dictStore.push("story-frame-mount-source", [...8 项...])
  → Pinia dictMap 就绪
```

### Step 2：MaDictSelect 渲染下拉

```
<MaDictSelect dict-name="story-frame-mount-source" v-model="selectedType" clearable placeholder="全部类型" />
  ↓
sourceData = dictStore.find('story-frame-mount-source') → 8 项
translatedOptions = computed(() => sourceData.map(item => ({
  ...item,
  _label: t(item.i18n)  // 响应式：locale 变 → computed 重算
})))
v-for item in translatedOptions:
  :value=item.value   // 'speech' | 'background' | 'material' | 'resource' | 'weather' | 'text' | 'stroke' | 'window'
  :label=item._label  // 预翻译结果
     // 例 item.i18n = 'storyStudio.mount.source.weather'
     // vue-i18n messages.zh_CN.storyStudio.mount.source.weather → "天气"
```

### Step 3：用户选择「天气」

```
点击 el-option → el-select 内置 emit update:modelValue 'weather'
  ↓ MaDictSelect defineModel() 代理
selectedType ref = 'weather'
```

### Step 4：过滤（DockFrameCol.vue）

```ts
const filteredFrameMountItems = computed(() => {
  if (!selectedType.value) return props.frameMountItems
  return props.frameMountItems.filter(i => frameMountSource(i) === selectedType.value)
})
```

`frameMountSource(i)`（labels.ts）返回 string value（'weather' 等），与 value 直接 `===` 比较。

### Step 5：列表标签翻译

每条 mount row 渲染：

```vue
<span class="dock-frame-col__mount-kind">
  {{ frameItemTypeLabel(item, vm.assetRows) }}
</span>
```

`frameItemTypeLabel` → 对 `speech`/`background`/`actor`/`resource` 分支 → 到 `frameMountSourceLabel(source)`：

```ts
useDictStore().t('story-frame-mount-source', 'weather') ?? 'weather'
```

→ dictStore.find 取到「weather 项」的 `label` → "天气"（注意：labels.ts 用的是 dictStore.t 离线 label，不走 vue-i18n，所以只显示中文硬编码）。

## 8. 常见坑位清单

| 坑 | 表现 | 解 |
| --- | --- | --- |
| 字典 .ts 加了项但 locale yaml 没加对应翻译 | MaDictSelect 下拉显示硬编码 label | 在 8 处 locale 补 i18n key 路径 |
| dictName 拼错（大小写/连字符） | MaDictSelect 空下拉 + dictStore.t 返回 null → ?? value 回退显示原值 | 核对 dictionary 目录文件名（.ts 名 = dictName） |
| i18n key 路径拼错（漏 storyStudio 前缀） | 翻译不生效，显示原 key 字符串 | 对照现有项：所有 story-* 字典 i18n key 以 `storyStudio.` 开头 |
| labels.ts 用 `dictStore.t` 但想要多语言切换 | 标签始终中文 | 需要多语言的标签改为：`useI18n().t('storyStudio.xxx.yyy')` |
| provider dict 扫描不生效（新建字典文件没被 glob 匹配） | 字典空 | 字典文件必须放在 `server/.../web/dictionary/` 与 `admin/.../dictionary/`（路径深度一致），后缀 `.ts` 或 `.js` |
| dictStore.push 返回 false（字典重复注册） | 后注册的字典项"不生效" | push 第三参传 `true`；或先 dictStore.remove(name) 再 push |
| 有 `<i18n>` 局部块但没用 `useScope: 'local'` | 局部翻译不生效，显示原 key | 改为 `useI18n({ useScope: 'local' })` |
| 语言切换后下拉选项不更新 | t() 没在 computed / 模板响应式上下文中调用 | 确保翻译在 computed 中计算，或模板中直接调用 t() |
| 在普通 ts 文件中用 `useI18n()` | 报错：必须在 setup 上下文中调用 | 改用 `import { t } from '@/utils/i18n.ts'` |
