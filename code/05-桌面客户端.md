# 桌面客户端 (desktop/)

基于 Tauri 2 的胖包架构，安装包含 ui、tools、cmd（7z 压缩），仅 `fastapp.phar` 从 CDN 下载更新。

## 目录结构

```
desktop/
├── src-tauri/           # Rust 后端
│   ├── src/
│   │   ├── main.rs      # 入口
│   │   ├── lib.rs       # 核心库
│   │   ├── commands.rs  # Tauri 命令定义
│   │   ├── bootstrap.rs # 启动引导
│   │   ├── manifest.rs  # CDN manifest 管理
│   │   ├── download.rs  # phar 下载
│   │   ├── health.rs    # 健康检查
│   │   ├── hardware.rs  # 硬件检测
│   │   ├── gpu.rs       # GPU 检测
│   │   ├── paths.rs     # 路径管理
│   │   ├── setup.rs     # 安装/更新
│   │   ├── state.rs     # 状态管理
│   │   └── process/     # Hyperf 进程管理
│   ├── Cargo.toml       # Rust 依赖
│   └── tauri.conf.json  # Tauri 配置
└── splash/               # 启动画面
```

## 架构特点
- **胖包设计**：UI、AI 推理工具、命令行工具（7z）内置
- **热更新**：仅 `fastapp.phar` 从 CDN 增量下载
- **Manifest 校验**：CDN manifest.schema.json 定义版本格式
- **多阶段构建**：详见 [desktop/ARCHITECTURE.md](file:///Users/wangxiansheng/Workspace/fastapp/desktop/ARCHITECTURE.md)
