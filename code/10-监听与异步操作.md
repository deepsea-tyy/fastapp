# 监听器与异步操作

Hyperf 事件系统的核心：事件（Event）→ 分发（Dispatch）→ 监听器（Listener）→ 处理（Process）。

## 监听器开发

### 定义事件

```php
namespace App\Common\Event;

class WsCloseEvent
{
    public function __construct(public int|string $userId) {}
}
```

### 创建监听器

```php
use Hyperf\Event\Annotation\Listener;
use Hyperf\Event\Contract\ListenerInterface;

#[Listener]  // 注解让 Hyperf 自动发现并注册
class YourListener implements ListenerInterface
{
    public function __construct(
        private readonly YourService $service,
        private readonly LoggerInterface $logger,
    ) {}

    public function listen(): array
    {
        return [WsCloseEvent::class];  // 可监听多个事件
    }

    public function process(object $event): void
    {
        if ($event instanceof WsCloseEvent) {
            try {
                $this->handleEvent($event);
            } catch (\Throwable $e) {
                $this->logger->error('Listener error: ' . $e->getMessage(), [
                    'exception' => $e,
                    'event' => $event::class,
                ]);
            }
        }
    }
}
```

### 分发事件

```php
// 推荐：异步执行，不阻塞主流程
Tools::eventDispatcher(new WsCloseEvent($userId));

// 不推荐：同步执行，会阻塞
$eventDispatcher->dispatch(new WsCloseEvent($userId));
```

### 自动注册流程

```
框架启动 → 扫描 #[Listener] 注解 → 调用 listen() → 建立映射 → 注册到事件分发器
```

### 监听多个事件

```php
public function listen(): array
{
    return [EventA::class, EventB::class, EventC::class];
}

public function process(object $event): void
{
    match (true) {
        $event instanceof EventA => $this->handleA($event),
        $event instanceof EventB => $this->handleB($event),
        default => null,
    };
}
```

## 异步操作

Hyperf/Swoole 协程环境中代码仍是同步顺序执行，真正异步并发需手动创建协程。

### 组件异步速查

| 组件 | 是否异步 | 推荐方式 |
|---|---|---|
| 事件分发 | 推荐 | `Tools::eventDispatcher()` |
| 日志记录 | 推荐 | `Tools::logAsync($message, $level, $name, $group)` |
| 队列分发 | 推荐 | `Tools::redisDispatcher($job, $delay)` |
| HTTP 请求 | 视情况 | 需要结果同步，不需要结果异步 |
| WebSocket 推送 | 推荐 | `Coroutine::create()`（详见 [06-WebSocket系统](06-WebSocket系统.md)） |
| 大文件操作 | 推荐 | 异步 |
| 缓存 / Redis / 数据库 | 不需要 | 协程安全，操作快 |
| 定时任务 | 不需要 | 独立进程执行 |

### 判断标准

需要异步：操作耗时 >100ms、不需要立即结果、可能阻塞主流程、批量操作。
不需要异步：需要结果、操作 <10ms、已协程安全、关键业务逻辑。

### 实现方式

**Tools 封装（推荐）**：
```php
Tools::eventDispatcher(new YourEvent($data));
Tools::logAsync('Message', 'info', 'app', 'error');
Tools::redisDispatcher($job, $delay);
```

**Coroutine::create（自定义场景）**：
```php
Coroutine::create(function () use ($data) {
    try {
        $this->doSomething($data);
    } catch (\Throwable $e) {
        Tools::logAsync('Error: ' . $e->getMessage(), 'error', 'app', 'error');
    }
});
```

### 注意事项

- 变量捕获用 `use` 关键字
- 异步操作中的异常不会自动传播，需手动处理
- 协程上下文自动传递
- 不要异步需要结果的操作——结果无法返回给调用者
