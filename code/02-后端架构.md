## 一、核心依赖与环境

| 依赖 | 用途 |
|---|---|
| `hyperf/framework` | 核心框架（Swoole 驱动） |

**环境要求**：PHP ≥ 8.1 · Swoole ≥ 5.0 · Composer ≥ 2.x · MySQL ≥ 5.7 · Redis ≥ 6.x

## 二、启动与运行

```bash
cd server
composer install
cp .env.example .env          # 配置数据库 & Redis
php bin/hyperf.php start      # 启动：http://127.0.0.1:9501
composer dev                  # 或热重载模式
```

**桌面部署**：`desktop/scripts/phar.sh` 直出 `build/.work/fastapp.phar`，`sfx.sh` 合成单文件 `fastapp`。开发环境可直接 `php bin/hyperf.php start`。

**常用 CLI**：
| 命令 | 用途 |
|---|---|
| `php bin/hyperf.php migrate` | 执行数据库迁移 |
| `php bin/hyperf.php gen:code` | 生成 CRUD 全套代码 |
| `php bin/hyperf.php plugin:install ds/storyStudio` | 安装插件 |
| `php bin/hyperf.php plugin:sync-admin` | 同步插件前端到 admin |

## 四、HTTP 请求处理链路

```
HTTP 请求
  → 路由 (config/routes.php)
  → 中间件 (CORS → Token/Permission → Operation)
  → Controller
    → 参数验证 (FormRequest)
    → 注入当前用户 (created_by/updated_by)
    → 调用 Service
  → Service
    → 业务逻辑处理
    → 调用 Repository（不直接操作 Model）
  → Repository
    → handleSearch 自动匹配查询
    → 操作 Model
  → Model
    → Hyperf ORM 读写数据库
  → 统一响应 Result（通过 Controller success()/error()）
```

### 4.1 Controller 层

**职责**：参数验证 → 数据准备 → 调用 Service → 返回响应。**禁止写业务逻辑**。

**Admin 与 Api 区别**：
| 类型 | 路由前缀 | 认证 | 中间件 |
|---|---|---|---|
| Api | `/api/*` | JWT Token（方法级） | `TokenMiddleware` |
| Admin | `/admin/*` | AccessToken + RBAC（类级）+ 操作日志（写方法级） | `AccessTokenMiddleware` + `PermissionMiddleware` + `OperationMiddleware` |

### 4.2 Service 层

**职责**：核心业务逻辑，调用 Repository 完成数据流转。

**约束**：
- 服务函数功能独立，不可交叉调用
- 删除操作必须用 `Db::transaction` 包裹

```php
class UserService extends IService
{
    public function __construct(protected UserRepository $repository) {}

    public function create(array $data)
    {
        return $this->repository->create($data);
    }
}
```

### 4.3 Repository 层

**职责**：封装数据库查询，提供统一数据访问接口。

**handleSearch 自动匹配**（无需重写即可使用）：
| 字段类型 | 查询方式 |
|---|---|
| 整数/浮点 | `where($field, $value)` |
| 日期时间 | 范围查询 `[start, end]` 或 `"start~end"` |
| 字符串 | `like "%value%"` |
| 数组 | `whereIn` |
| JSON | `whereJsonContains` |

**自定义查询**：
```php
public function handleSearch(Builder $query, array $params): Builder
{
    // 1. 特殊查询处理后 unset 掉已处理参数
    if (isset($params['phone'])) {
        $query->whereHas('profile', fn($q) => $q->where('phone', 'like', $params['phone'] . '%'));
        unset($params['phone']);
    }
    // 2. 预加载关联
    $query->with(['profile']);
    // 3. 必须调用父类处理剩余参数
    return parent::handleSearch($query, $params);
}
```

### 4.4 Model 层

```php
class User extends FastAppModel
{
    protected ?string $table = 'user';
    protected array $fillable = ['username', 'email'];
    protected array $casts = ['id' => 'integer', 'created_at' => 'datetime'];
    protected array $hidden = ['password'];
}
```

### 4.5 Request 参数验证

推荐 `ActionRulesTrait` 方式（按方法名自动匹配规则）：
```php
class UserRequest extends FormRequest
{
    use ActionRulesTrait;

    public function commonRules(): array    // 所有方法共用
    {
        return ['username' => 'string|max:16'];
    }

    public function createRules(): array    // 匹配 create 方法
    {
        return ['username' => 'required'];
    }

    public function saveRules(): array      // 匹配 save/update 方法
    {
        return ['username' => 'sometimes'];
    }
}
```

## 五、命名与代码规范

| 类型 | 规则 | 示例 |
|---|---|---|
| 文件名 | 大驼峰 | `UserController.php` |
| 方法名 | 小驼峰 | `getList()` |
| 变量名 | 小驼峰 | `$userId` |
| 删除 | 事务包裹 | `Db::transaction(fn() => ...)` |

**工程硬约束**：
- 严格分层：Controller → Service → Repository → Model，禁止跨层调用
- 服务间禁止互相交叉调用
- 所有操作跳过 `admin` 目录
- 不做向后兼容
- 不做 if 守卫判断或验证（用户规则）
- 不新增数据迁移文件（用户规则）

### 中间件链
| 中间件 | 触发时机 |
|---|---|
| `CorsMiddleware` | 全局：CORS 跨域 |
| `AccessTokenMiddleware` | Admin 类级：Token 校验 |
| `PermissionMiddleware` | Admin 类级：RBAC 权限校验 |
| `TokenMiddleware` | Api 方法级：Token 校验 |
| `OperationMiddleware` | Admin 写方法级：操作日志 |
| `TranslationMiddleware` | 全局：国际化 |

### RBAC 权限系统
`AdminUserService`（用户）→ `RoleService`（角色+权限分配）→ `Permission`（权限定义与检查）→ `DataScopeTool`（部门数据范围过滤）
