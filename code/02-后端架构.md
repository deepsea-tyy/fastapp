## 核心分层

### 1. Controller 层
位于 `app/Http/`，负责接收 HTTP 请求、参数验证、调用 Service、返回响应。

**关键基类：**
- [AbstractController.php](file:///Users/wangxiansheng/Workspace/fastapp/server/app/Common/AbstractController.php) - 所有控制器基类

### 2. Service 层
位于 `app/Http/*/Service/` 与 `plugin/ds/storyStudio/src/WebSocket/Service/`，封装核心业务逻辑。

**服务设计原则：**
- 所有服务函数必须独立，功能不可混合
- 服务仅可外部调用，不可互相交叉调用
- 删除操作使用 `Db::transaction` 确保原子性

### 3. Repository 层
位于 `app/Repository/`，封装数据库查询逻辑，提供统一的数据访问接口。

**关键基类：**
- [IRepository.php](file:///Users/wangxiansheng/Workspace/fastapp/server/app/Repository/IRepository.php) - 仓储接口

### 4. Model 层
位于 `app/Model/`，使用 Hyperf ORM 定义数据模型。

**关键基类：**
- [FastAppModel.php](file:///Users/wangxiansheng/Workspace/fastapp/server/app/Common/FastAppModel.php) - 模型基类

## 插件系统

### 命令行工具
位于 `app/Command/Plugin/`：

| 命令 | 用途 |
|---|---|
| `plugin:create` | 创建新插件 |
| `plugin:install` | 安装插件 |
| `plugin:uninstall` | 卸载插件 |
| `plugin:script` | 执行插件脚本 |
| `plugin:sync-admin` | 同步插件前端代码到 admin |

### 插件结构
```
plugin/{vendor}/{name}/
├── src/                    # PHP 源码
│   ├── Http/               # HTTP 控制器、服务
│   ├── WebSocket/          # WebSocket 服务
│   ├── Model/              # 数据模型
│   ├── Repository/         # 数据仓储
│   ├── Support/            # 辅助类
│   └── ConfigProvider.php  # 插件配置提供者
├── web/                    # 前端代码（自动同步到 admin）
│   ├── api/                # API 接口
│   ├── config/             # 模块配置
│   ├── dictionary/         # 字典数据
│   ├── locales/            # 国际化
│   └── views/              # Vue 页面与组件
├── Database/
│   ├── Migrations/         # 数据库迁移
│   └── Seeders/            # 数据种子
├── config.json             # 插件元数据
├── InstallScript.php       # 安装脚本
└── UninstallScript.php     # 卸载脚本
```
