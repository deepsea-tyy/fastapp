# FastApp 插件使用指南

插件根目录为 `server/plugin/<组织>/<插件名>/`。安装成功后目录下会有 `install.lock`；此后不能再次执行 `plugin:install`，改前端请用 `plugin:sync-admin`。

## 目录结构（示意）

```
plugin/ds/cms/
├── config.json          # 元数据与 composer / 前端依赖
├── install.lock         # 安装后存在
├── src/                 # PHP（ConfigProvider、Http、Model …）
├── Database/
│   ├── Migrations/
│   └── Seeders/
└── web/                 # 同步到 admin 的 src/plugins/ds/cms/
    ├── api/
    ├── views/
    ├── locales/
    └── assets/
```

## config.json 示例

```json
{
  "name": "ds/cms",
  "version": "1.0.6",
  "type": "mixed",
  "description": "内容管理插件",
  "author": [{"name": "ds"}],
  "composer": {
    "require": {},
    "psr-4": { "Plugin\\Ds\\Cms\\": "src" },
    "installScript": "Plugin\\Ds\\Cms\\InstallScript",
    "uninstallScript": "Plugin\\Ds\\Cms\\UninstallScript",
    "config": "Plugin\\Ds\\Cms\\ConfigProvider"
  },
  "package": { "dependencies": [] }
}
```

## 插件类型（创建时）

| `--type`（命令行） | `type`（config.json） | 说明        |
|-------------------|----------------------|-------------|
| `mix`             | `"mixed"`            | 前后端都有  |
| `frond`           | `"frond"`            | 仅前端      |
| `backend`         | `"backend"`          | 仅后端      |

`plugin:create` 里 **`--type` 只能写左列**（`mix` / `frond` / `backend`），不能写 `mixed`、`frontend` 等，否则可能报 `Plugin type is empty`。

## 命令速查

在项目 `server` 目录执行（`php bin/hyperf.php …`）。

| 命令 | 作用 |
|------|------|
| `plugin:local-list` | 本地插件列表及是否已安装 |
| `plugin:create <组织>/<插件名> --name="显示名" --type=mix --description="…" --author="…"` | 生成脚手架 |
| `plugin:install <path>` | 依赖、迁移、种子、**首次**拷贝 `web` → admin；`--yes` / `-y` 跳过确认 |
| `plugin:sync-admin <path>` | 仅覆盖同步 `web` → admin，**可反复执行**（`path` 同 install，如 `ds/cms`） |
| `plugin:sync-admin -a` | 对所有**已安装**且含 `web/` 的插件执行上一条 |
| `plugin:uninstall <path>` | 卸载；`-y` 静默 |
| `plugin:script <path> --show` | 查看可发布配置 |
| `plugin:script <path> --id=<ID> [--force]` | 发布配置 |

**admin 路径**：默认 `server` 上一级目录下的 `admin`，可通过配置 `plugin.front_directory` 修改。同步目标为 `admin/src/plugins/<path>/`。

**创建示例**：

```bash
php bin/hyperf.php plugin:create ds/cms --name="内容管理" --type=mix --description="内容管理" --author="ds"
```

## 开发要点

- **命名空间**：与 `composer.psr-4` 中声明一致，例如 `Plugin\Ds\Cms\`。
- **ConfigProvider**：返回 `annotations.scan.paths` 等，供 Hyperf 扫描。
- **InstallScript / UninstallScript**：可选，分别在安装、卸载时执行。
- **数据库**：迁移放在 `Database/Migrations/`，种子放在 `Database/Seeders/`；随 install / uninstall 执行或回滚（写法同 Hyperf 官方迁移 / Seeder）。
- **依赖**：Composer 包写在 `composer.require`；admin 前端 npm 包写在 `package.dependencies`（安装插件时会写入 admin 的 `package.json`）。
