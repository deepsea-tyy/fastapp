# 项目概述与整体架构

## 项目概述

**FastApp** 是一个企业级全栈应用框架，包含 Web 端、后台管理系统、桌面客户端、企业官网和后端服务。核心特色是集成了 **Story Studio** —— 一个个人数字资产创作中枢，提供小说到短视频的完整 AI 管线，包括：

- AI 图像生成（SDXL + Qwen-Image-Edit）
- 3D 姿势编辑与渲染
- 资源包（Bundle）管理
- 语音合成（TTS）与音乐生成
- 章节解析与场景提取
- 视频预览导出

## 整体架构

```
fastapp/
├── server/           # 后端服务（Hyperf 3.1 + Swoole）
│   ├── app/          # 核心应用代码
│   ├── config/       # 配置文件
│   ├── plugin/       # 插件系统（Story Studio 等）
│   └── databases/    # 数据库迁移与种子
├── admin/            # 后台管理前端（Vue3 + TS + Element Plus）
│   └── src/plugins/  # 前端插件（与后端插件对应）
├── desktop/          # 桌面客户端（Tauri 2 + Rust）
├── website/          # 企业官网（Nuxt.js 4.2）
├── tools/            # 本地 AI 推理服务（Python + uv）
├── cdn/              # CDN manifest 配置
├── script/           # 通用脚本（dev、dns 等）；桌面构建见 desktop/scripts/
└── docs/             # 项目文档
```
