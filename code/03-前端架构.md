# 前端架构 (admin/)

## 目录结构

```
admin/src/
├── components/             # 通用组件库
│   ├── ma-*               # 业务组件（表单、表格、上传等）
│   └── m-basic-ui/        # 基础 UI 组件
├── config/                 # 应用配置
├── directives/             # Vue 自定义指令
├── hooks/                  # 组合式函数
├── iconify/                # 图标数据
├── layouts/                # 布局组件
├── locales/                # 国际化语言包
├── modules/                # 功能模块
│   └── base/               # 基础模块（登录、权限、日志）
├── plugins/                # 插件前端代码（与后端插件对应）
│   └── ds/storyStudio/    # Story Studio 前端
├── router/                 # 路由配置
├── store/                  # Pinia 状态管理
├── utils/                  # 工具函数
├── App.vue                 # 根组件
├── bootstrap.ts            # 启动引导
└── main.ts                 # 入口文件
```

## 核心模块

### 1. 状态管理 (Pinia)
位于 `store/modules/`：

| Store | 职责 |
|---|---|
| `useUserStore` | 用户信息、登录登出 |
| `useMenuStore` | 菜单树、面包屑 |
| `useTabStore` | 标签页管理 |
| `useRouteStore` | 路由信息 |
| `useSettingStore` | 系统设置（主题、布局） |
| `useDictStore` | 数据字典 |
| `useWebSocketStore` | WebSocket 连接管理 |
| `useResourceStore` | 资源选择器 |
| `usePluginStore` | 插件管理 |

### 2. 路由系统
```typescript
// 静态路由位于 router/static-routes/
// 动态路由由后端菜单生成，通过 useRouteStore 管理
```

### 3. 通用组件库 (ma-*)

| 组件 | 用途 |
|---|---|
| `ma-form` | 高级表单（联动、校验、布局） |
| `ma-table` | 数据表格（分页、排序、筛选） |
| `ma-pro-table` | 专业表格（工具栏、打印、导出） |
| `ma-search` | 搜索面板 |
| `ma-upload-image` | 图片上传 |
| `ma-upload-file` | 文件上传 |
| `ma-editor` | 富文本编辑器（TinyMCE） |
| `ma-dialog` | 对话框 |
| `ma-drawer` | 抽屉 |
| `ma-resource-picker` | 资源选择器 |
| `ma-dict-picker` | 字典选择器 |
| `ma-json-editor` | JSON 编辑器 |
| `ma-icon-picker` | 图标选择器 |
| `ma-tree` | 树形组件 |
| `ma-auth` | 权限控制（按钮级） |

### 4. Hooks 组合式函数
位于 `hooks/`：

| Hook | 用途 |
|---|---|
| `useHttp` | HTTP 请求封装 |
| `useTable` | 表格逻辑封装 |
| `useForm` | 表单逻辑封装 |
| `useMessage` | 消息提示 |
| `useDialog` | 对话框控制 |
| `useDrawer` | 抽屉控制 |
| `useEcharts` | 图表初始化 |
| `useCache` | 缓存操作 |
| `useThemeColor` | 主题色管理 |
| `useImageViewer` | 图片预览 |

## 前端插件系统

插件前端代码从 `server/plugin/{vendor}/{name}/web/` 同步到 `admin/src/plugins/{vendor}/{name}/`。

**同步命令：** `php bin/hyperf.php plugin:sync-admin`

每个插件前端包含：
```
web/
├── api/            # API 接口定义（与后端路由对应）
├── config/         # 模块配置（菜单、路由）
├── dictionary/     # 前端字典（枚举、选项）
├── locales/        # 国际化文案
└── views/          # 页面组件
```
