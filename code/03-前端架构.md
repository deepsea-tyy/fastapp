# 前端架构 (admin/)

## 一、技术栈与环境

| 技术 | 版本 | 用途 |
|---|---|---|
| Vue | 3.5+ | Composition API 框架 |
| TypeScript | - | 类型安全 |
| Element Plus | 2.11+ | UI 组件库 |
| Pinia | 3 | 状态管理 |
| Vue Router | 4 | 路由 |
| Vite | 7 | 构建工具 |
| ECharts | 5.6+ | 图表 |
| TinyMCE | 7.7+ | 富文本 |
| Three.js | 0.170+ | 3D 渲染 |
| @pixiv/three-vrm | 3.4+ | VRM 模型支持 |
| Phaser | 3.90+ | 2D 场景引擎 |

**环境要求**：Node.js ≥ 20.0.0 · pnpm ≥ 10.x

## 二、启动与运行

```bash
cd admin
pnpm install
# 创建 .env（可选）：VITE_APP_PORT / VITE_APP_API_URL / VITE_APP_ROUTE_MODE
pnpm dev          # 开发：http://localhost:5173（或 3000）
pnpm build        # 生产构建 → dist/
pnpm gen:icons    # 生成离线图标集
```

## 三、目录结构

```
admin/src/
├── main.ts                 # 入口：挂载 App、初始化 Pinia/Router/图标
├── bootstrap.ts            # 启动引导：加载插件/字典/路由
├── App.vue                 # 根组件
├── components/
│   ├── ma-*               # 业务组件（ma-form / ma-pro-table / ma-upload 等）
│   └── m-basic-ui/        # 基础 UI 组件（m-button / m-input / m-drawer 等）
├── hooks/                  # 组合式函数（useHttp / useTable / useForm / useEcharts 等）
├── store/modules/          # Pinia Store（user / menu / tab / dict / websocket 等）
├── router/                 # 静态路由 + 动态路由（后端菜单生成）
├── layouts/                # 布局组件
├── modules/base/           # 基础模块（登录、权限、日志）
├── locales/                # 国际化 YAML（zh-CN / en 等）
├── config/                 # 应用配置
├── directives/             # Vue 指令（v-auth / v-role 等）
├── utils/                  # 工具函数（uploadLocal / chunkUpload 等）
├── iconify/                # 离线图标配置
├── plugins/
│   └── ds/storyStudio/     # Story Studio 前端（从插件同步）
└── provider/dictionary/    # 字典定义（启动自动加载）
```

## 四、应用启动链路

```
main.ts
  → createApp(App)
  → initIcons()                 # 加载离线图标集（pnpm gen:icons 生成）
  → bootstrap()
      → 注册基础模块 (modules/base/)
      → 注册插件前端 (plugins/*/)
      → 加载字典数据 (provider/dictionary + 插件 dictionary/)
      → 注册 Pinia Store
      → 注册 Router（静态路由 + 后端菜单动态路由）
      → 注册 Element Plus / 组件库 / 指令
  → app.mount('#app')
```

## 五、页面渲染链路

```
用户点击菜单 / 输入 URL
  → useRouteStore 匹配动态路由（后端菜单生成）
  → 路由守卫：useUserStore 校验登录态 → v-auth/v-role 校验权限
  → 加载布局组件 (layouts/)
      → 侧边栏菜单 (useMenuStore)
      → 标签页 (useTabStore)
      → 面包屑
  → 渲染页面组件 (views/ 或 plugins/*/views/)
      → ma-search 搜索面板
      → MaProTable 表格（集成分页、工具栏、操作列）
      → ma-form 表单（动态渲染表单项）
      → ma-dict-select / ma-dict-radio（字典选择）
      → ma-svg-icon（图标渲染）
```

## 六、状态管理 (Pinia)

| Store | 职责 |
|---|---|
| `useUserStore` | 用户信息、登录登出、Token |
| `useMenuStore` | 菜单树、面包屑导航 |
| `useTabStore` | 多标签页管理 |
| `useRouteStore` | 动态路由（后端菜单→路由表） |
| `useSettingStore` | 主题、布局、移动端判断（<1024px） |
| `useDictStore` | 数据字典：`find()` 查字典 · `t()` 翻译值 |
| `useWebSocketStore` | WebSocket 连接管理 |
| `useResourceStore` | 资源选择器 |
| `usePluginStore` | 插件管理 |

## 八、表单开发 (ma-form)

**链路**：`useForm('formRef')` → `setItems([...])` 配置表单项 → `validate()` 验证 → `getFormData()` 取数据

**配置项核心字段**：
| 字段 | 说明 |
|---|---|
| `label` | 标签文本（支持函数式 i18n） |
| `prop` | 字段名 |
| `render` | 渲染：`'input'` / `() => MaDictSelect` 等 |
| `renderProps` | 传给渲染组件的 props |
| `itemProps.rules` | Element Plus 验证规则 |
| `cols` | 响应式布局：`{ xs: 24, md: 12, lg: 8 }` |
| `hide` / `show` | 条件渲染：布尔值或 `(item, model) => boolean` |

**内置渲染器**：`input` / `textarea` / `select` / `datePicker` / `switch` / `radio` / `checkbox`

## 九、表格开发 (MaProTable)

**链路**：`options.requestOptions.api` 指定分页接口 → `schema.searchItems` 配置搜索 → `schema.tableColumns` 配置列 → `refresh()` 刷新

**列配置类型**：
| 类型 | 用途 |
|---|---|
| `selection` | 多选框列 |
| `index` | 序号列 |
| 普通列 | `prop` + `label` + `minWidth` + `cellRender` 自定义渲染 |
| `operation` | 操作列：`operationConfigure.actions` 配置 edit/delete/自定义 |

**搜索项配置**：与 ma-form 的表单项配置一致（label/prop/render/renderProps）。

## 十、图标系统 (ma-svg-icon)

### 使用方式
```vue
<!-- Iconify 图标（推荐） -->
<ma-svg-icon name="mdi:account" :size="20" />
<!-- UnoCSS 图标 -->
<ma-svg-icon name="i-carbon:user" :size="24" />
<!-- 自定义 SVG（放 admin/src/assets/icons/） -->
<ma-svg-icon name="custom-icon" :size="16" />
<!-- UnoCSS 行内类名 -->
<i class="i-carbon:user text-2xl"></i>
```

### 属性
| 属性 | 类型 | 说明 |
|---|---|---|
| `name` | string | 图标名（必填），格式：`前缀:图标名` |
| `size` | string\|number | 大小（20 或 '20px'） |
| `color` | string | CSS 颜色值 |
| `flip` | 'horizontal'\|'vertical'\|'both' | 翻转 |
| `rotate` | number | 旋转角度 0-360 |

### 常用图标集
| 前缀 | 名称 | 规模 |
|---|---|---|
| `mdi` | Material Design Icons | 5000+ |
| `ant-design` | Ant Design Icons | 800+ |
| `ep` | Element Plus Icons | 300+ |
| `heroicons` | Heroicons | 1200+ |

**查找图标**：https://icon-sets.iconify.design/

### 离线图标配置链路
```
开发阶段：pnpm gen:icons
  → 交互选择图标集
  → 开启离线模式
  → 生成：
      src/iconify/index.json （collections + isOfflineUse）
      src/iconify/data.json   （图标元数据，供选择器用）
      public/icons/*-raw.json （完整离线数据）

运行阶段：main.ts initIcons()
  → 遍历 iconify/index.json 中的 collections
  → downloadAndInstall(prefix)
  → 注入本地缓存，渲染时不再请求网络
```

**图标选择器**：`<ma-icon-picker v-model="iconName" />`（可视化搜索 + 分类）

## 十一、字典系统

**链路**：`admin/src/provider/dictionary/data/*.ts` + `plugins/*/dictionary/*.ts` → 应用启动自动加载 → `useDictStore()` 注册 → `MaDictSelect` / `MaDictRadio` / `MaDictCheckbox` 渲染

**字典定义**（文件名 = 字典名）：
```typescript
// admin/src/provider/dictionary/data/system-status.ts
export default [
  { label: '启用', value: 1, i18n: 'dict.enabled', color: 'primary' },
  { label: '禁用', value: 0, i18n: 'dict.disabled', color: 'danger' },
] as Dictionary[]
```

**使用**：
```typescript
const dictStore = useDictStore()
dictStore.find('system-status')          // 取完整字典数组
dictStore.t('system-status', 1, 'label') // 翻译值为 label
```
```vue
<ma-dict-select v-model="status" dict-name="system-status" />
<ma-dict-radio v-model="status" dict-name="system-status" render-mode="button" />
```

## 十二、响应式布局

### 断点
| 断点 | 宽度 | 设备 |
|---|---|---|
| xs | < 768px | 移动端 |
| sm | 768 - 992px | 平板 |
| md | 992 - 1200px | 中等屏 |
| lg | 1200 - 1920px | 大屏 |
| xl | ≥ 1920px | 超大屏 |

**移动端判断**：`useSettingStore().getMobileState()`（< 1024px 返回 true）

**响应式常用封装**：
```typescript
// 表单响应式标签位置
useFormResponsive(formRef, { xsLabelPosition: 'top', lgLabelPosition: 'right' })

// 抽屉响应式宽度
const { Drawer, open } = useDrawer({ xsSize: '90%', lgSize: '50%' })
```

## 十三、文件上传

| 场景 | 方式 |
|---|---|
| 普通图片 | `<ma-upload-image v-model="url" />` |
| 普通视频 | `<ma-upload-video v-model="url" :file-size="100*1024*1024" />` |
| 普通文件 | `<ma-upload-file v-model="url" />` |
| 自定义上传 | `uploadLocal({ file }, '/custom/path', 'fieldName')` |
| 大文件分片 | `shouldUseChunkUpload(file, 10MB)` → `chunkUpload({ file, chunkSize: 2MB, onProgress })` → 分片接口 `/attachment/chunk-upload` → 合并 `/attachment/chunk-merge` |

### 同步链路

```
server/plugin/{vendor}/{name}/web/   ← 开发在此目录写
    │  php bin/hyperf.php plugin:sync-admin
    ▼
admin/src/plugins/{vendor}/{name}/   ← 运行时从此加载
```

### 插件前端结构
```
web/
├── api/              # API 接口定义（对应后端路由）
├── views/            # 页面组件
│   └── */index.vue   # 列表页
│   └── */form.vue    # 表单页
├── config/           # 模块配置（菜单、路由）
├── dictionary/       # 字典（自动注册到 dictStore）
├── locales/          # 国际化文案
└── index.ts          # 插件入口（可选）
```
