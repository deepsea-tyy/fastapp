## 项目运行方式

### 环境要求

**后端：**
- PHP ≥ 8.1
- Swoole ≥ 5.0
- Composer ≥ 2.x
- MySQL ≥ 5.7 / PostgreSQL / SQLite
- Redis ≥ 6.x

**前端：**
- Node.js ≥ 20.0.0
- pnpm ≥ 10.x

**桌面端（可选）：**
- Rust 工具链（Tauri 系统依赖）
- WebView2（Windows）/ WebKit（macOS/Linux）

### 开发环境启动

#### 1. 后端服务
```bash
cd server
composer install
cp .env.example .env
# 编辑 .env 配置数据库和 Redis
php bin/hyperf.php start
# 或使用热重载：
composer dev
```

服务默认地址：`http://127.0.0.1:9501`

#### 2. 管理后台前端
```bash
cd admin
pnpm install
pnpm dev
```

前端默认地址：`http://localhost:5173`

#### 3. Story Studio 插件初始化
```bash
# 安装插件
cd server
php bin/hyperf.php plugin:install ds/storyStudio

# 执行数据库迁移
php bin/hyperf.php migrate

# 同步前端代码到 admin
php bin/hyperf.php plugin:sync-admin
```

#### 4. 桌面客户端（可选）
```bash
cd desktop
pnpm install
pnpm tauri:dev
```

### 生产部署

#### 后端打包为 Phar
```bash
cd server
php bin/hyperf.php phar:build
# 输出: fastapp.phar
```

#### 前端构建
```bash
cd admin
pnpm build
# 输出: admin/dist/
```

#### 桌面端打包
```bash
# 先构建前端
cd admin && pnpm build

# 再构建桌面端
cd desktop
pnpm tauri:build
```

### 常用 CLI 命令

**后端（server/）：**
```bash
php bin/hyperf.php start              # 启动服务
php bin/hyperf.php server:watch       # 热重载
php bin/hyperf.php migrate            # 执行迁移
php bin/hyperf.php gen:migration      # 生成迁移
php bin/hyperf.php db:seed            # 执行种子
php bin/hyperf.php gen:code           # 代码生成
php bin/hyperf.php plugin:list        # 插件列表
php bin/hyperf.php plugin:install     # 安装插件
php bin/hyperf.php plugin:sync-admin  # 同步插件前端
php bin/hyperf.php ws:show-stats      # WebSocket 统计
php bin/hyperf.php jwt:secret         # 生成 JWT 密钥
```

**前端（admin/）：**
```bash
pnpm dev           # 开发服务器
pnpm build         # 生产构建
pnpm lint          # 代码检查
pnpm gen:icons     # 图标生成
pnpm test:e2e      # E2E 测试
```
