## Story Studio 资产挂载统一管线（单一 actor 流程）

> 该条目避免反复确认资产流程的历史演进，请以本节为准。
> 所有资产（scene / character / prop / costume / creature / vehicle）在编辑、渲染、回放、选择四层完全走**同一 actor 管线**。不存在任何独立 background / 场景专属分支。唯一差异点通过 `asset_type` 字段在渲染最后一步注入。

### 核心原则

| 原则 | 含义 |
|---|---|
| 单一 DataIdType | 所有资产被选中时 `DataIdType = 'actor'`；仅台词为 `'speech'` |
| 单一 EditorElementKind | 所有资产渲染分类时 `EditorElementKind = 'mount' / 'material' / 'overlay' / 'window'`；`scene` 不产生额外 kind |
| 单一 FrameMountSource | 挂载源标签：`MOUNT_ACTOR_DB_TYPE` → `resource`，`MATERIAL_ACTOR_DB_TYPE` → `material`，`speech` → `speech`；scene 因属于 `MOUNT_ACTOR_DB_TYPE` 走 `resource` |
| 单一可见性互斥 | 同帧同 asset_id 只显示一个（选中优先，否则首个挂载）；scene 与 character/prop 共用该算法，不做排除 |
| 单一 action 调度 | 每帧动作采集 (`frameActionItems`) 遍历所有 frame actor 无跳过；scene 与人物一起进入 `actionController.playMany` |
| 单一渲染层 | 全部资产（含 scene）走 `actorLayer.ts` 的 `ensureVisuals → syncOne → setSelectedSlot` 流程；不再存在 `backgroundLayer.ts` 独立绘制路径 |
| 单一 runtime | 回放时 scene 进入 `SceneSnapshot.actors[]` → `sceneSnapshotToRuntime` → 写入 `runtime.actors[slotId]`，与人物共享 state 结构 |

### 唯一差异：`asset_type = 'scene'` 的全屏渲染标识

差异通过 `isSceneTypeActorOnFrame(actor, frame, assetRows)`（内部判定 `asset.asset_type == 'scene'`）生成布尔 `backgroundMode`，沿以下链路传导，**仅此一次判定**后不再做 scene 类型分支：

| 传导目标 | 字段/效果 | 视觉含义 |
|---|---|---|
| `EditorElement.backgroundMode` | `chrome='none'`；`picture='fullViewport'`；`motion='backgroundPose'` | 隐藏拖拽边框、标题条、锚点手柄；图片按 viewport 铺满不裁剪；动作采用基础位移动画 |
| `SelectionTarget.backgroundMode` | selection 层以全屏块渲染 | 选中时显示整屏蓝色选区，不裁剪 actor 图像边界 |
| `mountAssetOnFrame` 默认参数 | `state_key = 'scene'`；`stack_order = 0`；`offset_x/offset_y = 0`；`start_ms = actorStartTimeMin`；`visible = true` | scene 挂载时默认为最底层、居中起点；该默认值仅为 asset 级合理默认，不参与后续类型判断 |

**注意：** `backgroundPose` 在 `motion.ts` `resolveElementPose` 中是 fall-through 到 `mountAction`，共享同一套解算（保留语义，不做独立分支）。

### 资产挂载流程（scene 与 character 完全一致）

```
用户在资产面板拖入/点击 asset（任意 asset_type）
    │
    ▼
sceneAsset.ts dropAssetToActiveScene / dropMaterialToActiveScene
  → ensureActiveFrame → activeFrameFromPresentation(pres)
    → frames[activeSegmentIndex(pres)]（统一用 __activeSegmentIndex 下标取帧）
    │
    ▼
mountAssetOnFrame (presentation/actor/mount.ts)
  ① 查询 asset.asset_type 得到默认 state_key / stack_order
     - scene → state_key='scene', stack_order=0
     - character/prop/creature → state_key 来自 asset 配置, stack_order≥1
  ② 构造 StoryPresentationActorRow (actor_type = MOUNT_ACTOR_DB_TYPE)
  ③ attachPresentationActorToShot → 写入 frame.story_presentation_actor
  ④ 产生 frame change 事件
    │
    ▼
buildEditorRuntimeForFrame
  遍历所有 frameActors (无类型跳过)，为每个 actor 生成 RuntimeActorState
  scene 不产生独立 background 字段
    │
    ▼
actorLayer.ensureVisuals / syncAll (无 scene 跳过 continue)
  为 slot 创建 image + container + chrome
  backgroundMode=true 时 chrome='none'（仅视觉差异）
    │
    ▼
applyFrameActorsToRuntime（可见性互斥 exclusiveSameAsset 作用于 scene 与 character 同一 map）
  同 asset_id 的 scene 若挂两份：只显示选中的那份（与人物一致）
    │
    ▼
resolveElementPose：backgroundPose → mountAction（同一解算函数）
```

> **统一挂载取帧管线**：资源库拖拽 / 素材列表拖拽 / 对白挂载 / 叠加层添加 全部通过 `activeFrameFromPresentation(pres)` = `frames[__activeSegmentIndex]` 取当前帧。`__activeFrameId` 冗余字段已删除。`syncTimelineMeta` 不再覆盖 `__activeSegmentIndex`（避免时间解析覆盖用户选择）。详见 [编辑器时间线链路.md](file:///Users/wangxiansheng/Workspace/fastapp/server/plugin/ds/storyStudio/docs/code/编辑器时间线链路.md)。

### 回放/播放（buildSceneSnapshotAtTime）流程

```
scene 与 character/prop 无差异：
  for actorRow of frameActors：
    不再存在 `if (isSceneTypeActorOnFrame) continue`
    计算 actorVisibleAt / pickActionAtActorLocal / motionPose / idle
    push 到 SceneSnapshot.actors[]
  （历史字段 SceneSnapshot.background / BackgroundSnapshot 已删除）

→ sceneSnapshotToRuntime：scene 写入 runtime.actors[slotId].alpha/x/y/scale… 同人物
→ actorLayer.syncOne：不再 setVisible(false)，正常显示
```

### 选择/删除流程（scene 与 character 完全一致）

| 步骤 | scene | character / prop |
|---|---|---|
| `selectionTargetFromActor` | `form = 'actor'`，type = `'actor'` | 相同 |
| `dataIdFromFrameItem` | `toDataId('actor', actorRuntimeKey(item.actor))` | 相同 |
| 删除（Delete 键） | `parsed.type === 'actor'` 分支 → `removePresentationActorFromScene` | 相同 |
| frame 结构挂载 relations | `frameActorRelationsPayload` 遍历所有 actors，scene 无独立 syncFrameMounts 分支 | 相同 |

### 禁止使用的遗留概念（遇到必须删除，不要兼容）

| 禁止项 | 说明 | 替代 |
|---|---|---|
| `kind == 'background'` | 原 `StoryFrameItem.kind` 的独立背景项类型 | 所有资产统一为 `kind == 'actor'`（`item.kind == 'actor'` → `item.actor.asset_type` 细分） |
| `DataIdType = 'background'` | 原选择层独立背景类型 | 用 `'actor'` + `asset_type='scene'` 从 actor 表反查 |
| `EditorElementKind = 'background'` | 原渲染层背景 kind | 用 `'mount'` + `backgroundMode=true` |
| `FrameMountSource = 'background'` / `mount.source.background` | 原挂载源字典项 | 删除字典项；scene 挂到 `resource`（MOUNT_ACTOR_DB_TYPE） |
| `backgroundLayer.ts` 及导入 | 原独立背景渲染层（只取第一个 scene） | 删除该文件，scene 走 actorLayer（支持多个 scene） |
| `drawBackground()` / `syncBackgroundFromRuntime()` / `paintBackground()` | 原 StoryContentScene / contentScenePlayback 的独立背景 API | 删除；统一 `actorLayer.syncAll(runtime)` + `overlayEditor.refreshOverlays()` |
| `BackgroundSnapshot` 类型 / `SceneSnapshot.background` 字段 | 原回放层独立快照 | 删除；scene 资产信息从 `SceneSnapshot.actors[]` 获取 |
| `resolveBackgroundPoseFromFrame()` / `backgroundSnapshotToPose()` / `backgroundElementStub()` | 原独立位姿解算函数 | 删除；`backgroundPose` fall-through 到 `mountAction` |
| `isSceneActorRef()` / `primeFrameBackground()` / `skipBackgroundSync` | frameDisplay 中为了绕过 actorLayer 而存在的桥接函数 | 全部删除 |
| `clearAllSceneActorsOnFrame()` | 为 scene 独立互斥而写的函数（dead code） | 删除；scene 与人物共享 exclusiveSameAsset |
| `EditorResourceOption.kind = 'scene'` / `listEditorResources()` scene 分支 | 原面板中 scene 与 actor 独立列出 | 删除类型与函数，全部统一为挂载后的 actor 列表 |
| `applyFrameActorsToRuntime` 中 `if (isSceneTypeActorOnFrame) state.visible = actorRow.visible` | scene 不走互斥逻辑的遗留分支 | 删除；scene 与人物一起走 exclusiveKeys 判断 |

> 判断某段遗留代码是否应该删除：**只要它以"scene 是特殊类型需要独立处理"为前提，一律删除。** scene 唯一合理的特殊处理只有"mount 默认参数 + backgroundMode 全屏渲染"这两个位置，其余均复用。
