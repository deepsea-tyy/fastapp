# 数据库备份工具

三个命令统一在 `App\Command`，共用 `AbstractBackupCommand`，命令前缀均为 `ds:backup-*`。

## 命令概览

| 命令 | 功能 | 输出 / 输入 |
|------|------|-------------|
| `ds:backup-migrations` | 备份非插件表结构为迁移文件 | `databases/migrations/*.php` |
| `ds:backup-seeders` | 备份非插件表数据为 SQL | `databases/seeders/*.sql` |
| `ds:backup-import` | 导入备份 SQL 到数据库 | 读取 seeders / 绝对路径 |

## 1. 备份迁移结构 (`ds:backup-migrations`)

从现有数据库表结构备份迁移文件，自动过滤插件表，合并到一个文件。

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--force` | 是否强制覆盖已存在的文件 | false |
| `--prefix` | 数据库表前缀 | 从环境变量 `DB_PREFIX` 读取 |
| `--filename` | 生成的文件名 | all_tables |
| `--table` | 指定表名，支持逗号分隔多个（如 `users,orders`） | 空（默认导出全部非插件表） |
| `--with-data` | 是否在迁移文件中追加 INSERT 数据语句 | false |
| `--data-limit` | 开启 `--with-data` 时每个表最多导出的数据条数 | 1000 |

### 使用示例

```bash
php bin/hyperf.php ds:backup-migrations
php bin/hyperf.php ds:backup-migrations --table=users,orders
php bin/hyperf.php ds:backup-migrations --with-data=true
php bin/hyperf.php ds:backup-migrations --table=users,orders --with-data=true --data-limit=200
php bin/hyperf.php ds:backup-migrations --filename=production --force=true
php bin/hyperf.php ds:backup-migrations --prefix=app_
```

输出：`databases/migrations/YYYY_MM_DD_HHMMSS_{filename}.php`

## 2. 备份表数据 (`ds:backup-seeders`)

从现有数据库表数据备份 SQL，过滤插件表，支持自动分片。

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--force` | 是否强制覆盖已存在的文件 | false |
| `--prefix` | 数据库表前缀 | 从环境变量 `DB_PREFIX` 读取 |
| `--filename` | 生成的文件名 | all_data |
| `--limit` | 每个表最多导出的记录数 | 1000 |
| `--chunk-size` | 分片文件大小（MB） | 10 |

### 使用示例

```bash
php bin/hyperf.php ds:backup-seeders
php bin/hyperf.php ds:backup-seeders --limit=5000 --chunk-size=50
php bin/hyperf.php ds:backup-seeders --filename=backup
```

输出：`databases/seeders/YYYY_MM_DD_HHMMSS_{filename}.sql`  
超大时追加：`{filename}_part2.sql`、`_part3.sql` 等

## 3. 导入备份 SQL (`ds:backup-import`)

导入备份 SQL 文件到数据库。

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `file` | SQL 文件路径（必需，支持相对/绝对路径） | - |
| `--skip-errors` | 是否跳过错误继续执行 | false |
| `--transaction` | 是否使用事务执行 | true |
| `--batch-size` | 批量显示进度的语句数 | 100 |

### 使用示例

```bash
# 相对路径，相对于 databases/seeders
php bin/hyperf.php ds:backup-import 2025_11_08_070209_all_data.sql
php bin/hyperf.php ds:backup-import /path/to/file.sql
php bin/hyperf.php ds:backup-import file.sql --skip-errors=true
php bin/hyperf.php ds:backup-import file.sql --transaction=false
```

## 工作流程示例

```bash
# 1. 备份表结构
php bin/hyperf.php ds:backup-migrations --filename=production_tables

# 2. 备份数据
php bin/hyperf.php ds:backup-seeders --filename=production_data --limit=10000 --chunk-size=50

# 3. 新环境恢复
php bin/hyperf.php migrate
php bin/hyperf.php ds:backup-import 2025_11_08_070209_production_data.sql
```

## 最佳实践

1. **定期备份**：使用 `ds:backup-seeders` 定期生成数据备份
2. **版本控制**：迁移文件纳入版本控制，数据文件使用 `.gitignore` 忽略
3. **测试导入**：生产环境导入前，先在测试环境验证
4. **分片管理**：大数据量合理设置 `--chunk-size`，避免单个文件过大
5. **错误处理**：生产环境使用事务模式，确保数据一致性
