# 国际化

## 语言

**`middleware.Translation`** 读 **`Accept-Language`**，[`NormalizeLocale`](../internal/app/i18n/i18n.go) 得到 **`en`** 或默认 **`zh_CN`**，写入 **`c.Set(i18n.ContextLocaleKey, loc)`**。

业务：**`i18n.FromGin(c)`** 或 **`middleware.Locale(c)`**。

## 词条

核心 JSON：**`{根}/storage/locales/`**（`en`、`zh_CN`），启动 **`i18n.Init(StorageLocalesDir(root))`**。  
**`i18n.T(locale, key)`**：无键则返回 key；`en` 缺条回退 **`zh_CN`**。  
运行期 **`i18n.Merge(locale, map)`**（后写覆盖）。

## 与 `response` 的联动

`message` 等于 **`defaultMessage(code)`** 时，`response.JSON` 替换为 **`ResultMessageKey(code)`** 对应词条。见 [`resultcode.go`](../internal/app/common/response/resultcode.go)。
