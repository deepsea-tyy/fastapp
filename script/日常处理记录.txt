API 响应处理
DioClient 拦截器会自动处理 API 响应：
1. 自动检查 code 状态码，code != 200 时抛出异常
2. 自动解包 data 字段，直接返回 data 内容

重要规则：
- 不要检查 response['code'] == 200
- 不要访问 response['data']
- response 已经是解包后的 data 内容，直接使用
- 使用 try-catch 捕获异常即可
- 成功请求，不使用返回的message做提示

示例：
final response = await userApi.updateProfile(username: username);
final user = User.fromJson(response);  // response 直接就是数据
